# Codex 浅色 UI 与五页平铺交接日志

日期：2026-08-26

分支：master

## 目标与结果

本次将开发版桌面 UI 固定为浅色 Codex 风格。左侧滚动导航保留五个一级入口：通用设置、账号设置、任务、活动、测试功能。程序设置、关于、重启和调试仍在底部辅助区；页面实例不因导航切换销毁。

补丁修复：当开发版缺少 `configs/account_master_config.json` 时，账号/序列页面不再让整个窗口退出，而是保留界面并显示仓库暂不可用，等待完整性审查进行恢复或导入。

## 代码变更

- 新增 `src/gui/CodexTheme.py`、`src/gui/SectionPanel.py`、`src/gui/FlatSettingRow.py`。
- `custom_ok/ok/gui/MainWindow.py` 在窗口初始化时注入固定浅色 palette/QSS，并忽略系统深色模式通知。
- `src/gui/GeneralSettingsTab.py` 将四个既有设置对象放入统一区块壳层，保留 `start_panel`、`trigger_panel`、`hotkey_config` 和 executor 接口。
- `src/gui/AccountSettingsTab.py`、`src/gui/ActivityHubTab.py` 去除内部 `QTabWidget`，直接纵向加入现有账号、序列、维护和活动任务实例。
- `src/gui/TaskHubTab.py`、`src/gui/TestHubTab.py` 增加统一区块说明；测试页明确“账号切换测试（多账号每日任务测试）”。
- `custom_ok/ok/gui/settings/SettingTab.py` 将主题选项锁定为浅色，程序设置仍保存程序本身配置。
- `src/gui/AccountConfigTab.py`、`src/gui/SequenceManagementTab.py` 捕获账号仓库缺失/损坏错误，进入可见安全状态。

## 安全边界

账号保存、序列成员修改、删除二次确认、配置备份、CAS 修订、原子发布和完整性门禁未搬迁。没有导入 Android、MuMu、ADB 或自动战斗代码。任务页窗口尺寸内部诊断日志过滤逻辑仍保留在文件日志中。
