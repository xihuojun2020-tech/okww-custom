## Current project version

The personal-maintained source branch is **1.84.01**. See the [changelog](https://github.com/xihuojun2020-tech/okww-custom/blob/v1.84.01/更新日志.md) for the exact release history. This repository is [xihuojun2020-tech/okww-custom](https://github.com/xihuojun2020-tech/okww-custom); it is separate from the [upstream ok-oldking project](https://github.com/ok-oldking/ok-wuthering-waves). Releases and downloads from one repository do not indicate the version or verification status of the other.

Recent feature notes:

- [Auto Sea of Ruins](references/sea-ruins.md): start from a currently open floor detail page between 7 and 11, then challenge through floor 11. Floor 11 recognition was fixed in 1.84.01. The complete 7–11 run has not been established as fully verified in live gameplay.
- [Resonant Sonic Simulation](references/resonance-simulation.md): enter and navigate the activity manually; the task provides combat only, without automatic navigation, target recognition, or reward collection.
- [Completion evidence](references/completion-evidence.md): account to-do items are for display and manual tracking. They are separate from the completion-check system and do not launch tasks.
