# GameFrame v67 管理迁移复核

本轮独立包已接通真实任务/全局配置、本地诊断及已安装游戏包更新入口。只读复核发现的缓存损坏无法重下、UTF-8 BOM误判依赖变化两处问题已由主代理修复；主代理报告修复后17项更新检查通过。本记录不替代最终ZIP/wheel安装验收、备份或发布结果。

## 范围与证据

复核范围为 `NativeConfigurationTab`、无设备配置JSONL进程、`ManagementWindow` 保存/关闭生命周期、原生诊断入口、原生更新服务/卡片、发布清单、核心事务及启动器owner协调。复核仅阅读源码和diff；前阶段的两个故障使用临时目录、完整索引游戏包和本地transport复现，未访问NAS、真实账号、游戏或模拟器。本次文档同步没有重复运行测试。

配置由生产任务metadata导出，配置进程处理 `get-schema`、`set-config`、`invoke-action`，保存后返回更新schema。管理关闭先请求配置进程停止，尚未退出时明确报错并保留窗口。启动器长期保存设备/选中任务，独立包业务配置交给配置owner，本次覆盖JSON不再重复持久化。

诊断用用户数据目录作为root，执行器提供已有帧缓存的复制遮盖结果；管理窗口禁用需要设备的测试截图。原生 `local_only` 不启动上传器、NAS保留维护或旧计划任务修改，用户主动点击的连接测试/打包上传仍使用原传输边界。

## 已修复的更新故障

| 复现 | 根因与修复 |
|---|---|
| 正常下载后损坏缓存，再下载立即失败，新增transport调用为0 | 原生长度/SHA失败曾抛 `LanUpdateError`，与缓存清理捕获的异常类型不一致。改用缓存校验所支持的 `UpdatePackageError`，保留身份/真实依赖错误的明确拒绝。 |
| requirements只增加UTF-8 BOM，服务接受而核心拒绝 | 服务使用 `utf-8-sig`，核心曾使用 `utf-8`。核心现使用 `utf-8-sig`，保持空行、注释和行首尾空白的既有规范化。 |

## 新增保护分支的依据

| 分支 | 对应的实际边界或用户要求 |
|---|---|
| JSON对象、键、精确类型、范围、选项与只读配置验证 | JSONL是管理UI/执行owner的外部请求边界；生产metadata定义可写范围，布尔与整数不可混用。 |
| 动作所属任务和无设备动作限制 | 管理进程明确不拥有capture/input，不能调用依赖执行设备的按钮。 |
| 关闭等待后台操作、配置子进程未退出则报告失败 | 避免在配置保存、诊断打包或更新下载过程中销毁实际owner；不把未停止当成成功。 |
| `local_only` 与诊断观察失败报告 | 独立包不得隐式访问NAS；诊断故障不得改变任务结果或禁用自动战斗意图。 |
| 已安装路径、索引、包ID/版本、外层大小/SHA及requirements检查 | ZIP/发布清单属于外部输入；仅替换已安装代码，避免覆盖源码、混包或在现有环境执行真实变化的依赖。 |
| 事务phase及恢复树身份检查 | 支持真实rename/中断失败后的恢复，防止将错误树恢复为已安装包。 |
| `_updating`、启动/停止/管理状态与两个Controller空闲检查 | 当前启动器必须串行化代码替换与自己持有的执行/管理进程。 |

所审范围内未发现需要凭假设新增的保护机制；本轮未增加代码、异常捕获、重试或兜底。没有新的有证据阻断问题。Qt保存/关闭未发现新的具体故障，不代表全部GUI交互已做实机验收。
