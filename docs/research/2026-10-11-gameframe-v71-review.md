# GameFrame v1.97.71 代码复核

本阶段迁移原生角色编辑和多任务脚本包。主代理复核配置协议、界面状态、素材注册和发布物；三个代理分别复核角色保存、脚本包存储与运行 owner。剩余设备、热键通知、手动工具和存储入口继续迁移。

角色保存与使用模式保留旧文件契约，独立进程验证真实构造，不借用游戏设备。保存不自动改变其他运行 owner；显式重载先构造全部候选，再释放输入、提交映射并更新该 owner 的应用版本。战斗角色保留必要观察字段，代码变化后重新核验队伍和轮转状态。草稿模式与磁盘模式分开维护，取消与失败不丢稿。

脚本包沿用一个目录注册表，按逻辑包身份与 task key 生成稳定 UUID。整组源码与素材原子发布为不可变快照，素材变化进入完整任务定义 revision。FeatureSet 与任务注册表作为同一候选提交，失败恢复旧特征与任务。导出排除私人配置并禁止覆盖已有输出；删除保留配置和历史。旧包转换只改已确认 API 的 import 目标，未知依赖明确拒绝，迁移差异与任务定义可预览。

复核发现旧导入实际接受中文逻辑包名，新增 ASCII 限制没有输入契约依据，已删除；包路径仍使用 UUID，真实相对资源路径与 ZIP 边界检查保留。删除了 resolve 后失效的符号链接重复分支，ZIP 提取复用核心已有检查。修复 metadata 未携带 group_name/import_namespace 的接线遗漏。旧测试 host fixture 补齐新的应用版本字段，没有在生产代码增加容错默认值。

新增保护依据均为真实外部包/代码输入、并发版本冲突、数据丢失防护及单一输入 owner 契约。没有增加普通故障停用战斗、吞异常、自动反复重载或重复设备采集。验证进程隔离配置状态，但用户 Python 是可信代码，不是权限沙箱。MIT 核心与 AGPL 鸣潮派生包许可边界继续保留。
