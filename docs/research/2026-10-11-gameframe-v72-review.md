# GameFrame v1.97.72 独立代码复核

本次复核设备图形编辑、桌面热键与通知、管理窗口到执行进程的 live bridge，以及原生输出目录迁移。依据当前 v72 diff、实际后端接口、已有存储事务和离线 Qt／合成进程证据。只修改了分工授权的设备编辑输入边界、管理窗口证据目录及原生日志目录；本报告不承担版本、构建与发布。没有连接 NAS、游戏或模拟器，没有发送真实输入、启动真实设备或执行系统定时任务。

设备编辑器沿用 `create_device` 的字段契约，保留未由图形字段表示的高级参数和未修改的可空参数。能力直接读取后端类声明，MuMu 只声明 `frames`、`multitouch`，没有添加键盘能力。Windows 枚举只在显式刷新时调用只读窗口 API，初始化和参数编辑不创建设备。复核确认三个实际输入故障：缺少 `type` 的 JSON 曾将 `KeyError` 传播出 Qt 槽；图形整数输入非法时未发出更新信号，启动曾沿用上一次合法 JSON；未知高级后端被编辑器拒绝后，启动曾仍读取该无效 JSON。分别在编辑器的外部对象边界明确报错，并在启动前先验证待编辑字段、再验证当前高级配置，避免用旧状态掩盖输入失败。

管理与运行共享同一执行 owner，管理窗口通过 UUID 请求标识、JSONL 管道和 Qt 排队信号请求设备动作。独立配置进程保留非设备配置操作；没有在管理窗口另建采集或输入 owner。特征码返回后继续检查所提交账号及 revision，再由既有确认流程绑定。执行响应按请求来源转发，特征码结果不追加到 launcher 的公共输出；管理退出清理管理路由，执行退出为剩余请求返回明确失败并清空路由。没有新增自动重试、超时假成功或强制取消用户服务意图。

复核发现管理退出时调用完整包选择流程，会重新启用运行期间的设备字段，并清空已检测到的技能热键冲突。live 会话退出管理窗口现只刷新任务，保留原设备锁定、保留冲突列表。热键采用按下状态变化触发，通过已有 pause/resume 协议保留服务启用偏好；冲突键停用其暂停功能并给出提示。托盘通知保留显式关闭设置，普通关闭按用户设置进入托盘；托盘“退出”和任务成功后的退出设置强制走关闭与 owner 清理流程，避免被关闭到托盘设置误隐藏。

输出迁移复用已有复制、哈希校验、SQLite 一致性快照和原子配置提交。配置权威固定为会话数据根的 `configs/runtime_storage.json`，不从源码根或其他安装发现私人资料；账号、任务配置、用户脚本和运行控制状态留在数据根。沿用既有迁移策略，日志和缓存仍映射到数据根，界面展示实际选定路径。原生截图、完成证据和日志 writer 均通过显式 `repo=data_root` 读取存储配置。复核发现原生预备阶段先用硬编码目录初始化证据单例，迁移后的 host 再绑定新目录会失败；预备阶段、host 和管理窗口已统一使用同一存储权威。共享监控目录按截图和录像的实际布局分别列清单，排除重复证据、诊断及 runtime 控制资料；初次列清单与提交前复核使用相同过滤规则，原文件保留。

另一个已确认根因是迁移配置已经提交后，重绑证据或重建管理页面失败，旧页面仍可能使用旧目录。当前代码将这类失败明确标记为已提交失败，停止重启配置 owner，并禁用旧账号、配置、脚本、角色、维护、存储、完成证据和诊断入口，要求重新加载管理窗口。没有声称回滚已经提交的磁盘配置，也没有返回“未保存”或“未提交”掩盖提交状态。该分支处理已注入复现的提交后失败，证据与诊断入口的停用属于防止旧目录继续写入的必要修复。

新增保护分支的依据限定于真实外部 JSON／管道输入、现有 HWND 接口契约、账号 revision 冲突、单一 owner、迁移预览过期、目录归属和数据丢失防护。设备编辑失败会显示错误并阻止启动；目录不存在或无法打开会明确失败；迁移中来源变化、其他 owner 占用、目标与来源相互包含以及未归属目标资料均拒绝提交。没有增加 MuMu 索引范围等后端未声明的限制，没有以空值、备用目录或无界重载掩盖故障。MIT 核心新增文件不导入 `src` 业务代码，鸣潮派生业务仍在标明 AGPL-3.0-or-later 的游戏包内，原素材与模型许可不变；可信用户 Python 和设备参数不是权限沙箱。

本代理已执行设备编辑器与 Windows 元数据的 10 项离线检查，以及缺失类型、会话证据目录和日志目录的定点检查；日志未配置迁移时的原目录行为也通过。另用实际 Qt 和合成运行进程对象复核图形非法值、高级 JSON 保留、live 私有响应、管理退出冻结、冲突保留、执行退出路由清理和任务完成强制退出。后续 root 修复通过当前 diff 确认；完整 v72 打包与管理迁移验收由主代理记录，不将读取测试源码等同于运行通过。未验证真实 HWND 采集、MuMu DLL、ADB、系统托盘交互、物理热键、真实 OCR 或真实磁盘中断恢复。本轮没有新发现的未处理阻断项；结论限于所述代码与离线边界。
