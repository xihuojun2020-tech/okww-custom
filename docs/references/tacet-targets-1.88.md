# 新增无音区与旧选择兼容（1.88.03）

沉心域、烬心域插入当前列表最前面，第一组由2项变为4项，列表按 `[4,5,5,7]` 共21项定位。前四项为沉心域、烬心域、方擎西峰、玄幽东岳。

账号界面按当前列表顺序排列，新增两项显示“沉心域无音区”“烬心域无音区”，其他项保留原编号“第1个无音区”至“第19个无音区”作为代称；保存值与当前列表位置分开。旧选择1～19仍对应原关卡，运行时定位到原位置加2；新增保存值20为沉心域、21为烬心域。升级或导入旧备份无需改写账号选择值，原默认值1继续指向方擎西峰。

无音区页进入后恢复右侧列表顶部，使用现有指南滚动定位。简体中文首屏已知地点核对名称与同行按钮；其他地点按更新后的列表位置定位。前往与直接挑战分别识别，实际地图不可快速到达时报告未解锁，不修改账号选择。可进入的挑战沿用原队伍、战斗、体力预算、领奖和再次挑战流程。

未确认的配置值不能自动改选其他关卡。当前已通过新增首屏截图的实际OCR验证；其他区域顺序依据既有列表和本次新增首组信息，未获得全列表新截图。实际解锁后入场及对局仍需使用端验收。
