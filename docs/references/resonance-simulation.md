# 群声共振模拟域自动战斗（1.83.05）

入口：任务 → 活动 → 群声共振模拟域。玩家手动进入活动、移动、交互、选择奖励及进入下一关；在需要战斗时点击开始，活动结束后停止。`技能间隔`可设为 0.5–10 秒，默认 2 秒。游戏在前台时按 `/ ?` 共用物理键暂停或继续本任务。

这是独立的单角色战斗任务。连续两帧看见技能栏后，持续普攻并按设定间隔尝试 E；Q 只在外围完整黄色充能圆环连续确认后释放。技能次数、冲刺次数、混搭技能图标以及部分充能黄弧均不作为触发条件。技能栏消失、加载、菜单、切出游戏或暂停时释放输入并等待，不执行移动、交互或选择。支持简体中文；活动结束需手动停止。

## 旧版设计存档（1.79.01）

1.79.01 的下列自动导航方案及当时的离线验证记录已由 1.83.05 的纯自动战斗实现替代，仅留作历史设计参考，不代表当前按钮行为。

### 自定义目标文字

展开配置，“目标文字”每行填写一条，排在上面的优先：

```text
奖励|行动资金
奖励|共鸣因子
下一关|藏宝地
下一关|战斗区域
```

- 阶段可填 `奖励`、`下一关`、`通用`；只有关键词时视为通用。
- 奖励在“收集奖励”和“前往下一个区域”两个阶段都可以处理，避免提示先变化导致漏捡。下一关目标只在“前往下一个区域”阶段处理。
- 默认包含匹配：“共鸣因子”可匹配“共鸣因子·奥古斯塔”等完整名称。开启“精确匹配文字”则要求全文相同。
- 通用规则在已确认的移动/领奖/下一关阶段生效；不会因为菜单或教学文字相同而点击。
- 优先级按输入顺序；同优先级保留已跟踪对象，避免在多个敌人或目标间来回切换。
- 关键词需要关联下方金色或绿色奖励物/入口底座，才能作为移动目标。新外观可能需要补充视觉规则；不是任意文字都能自动导航。

### 移动与战斗

有文字目标时关联物体下缘/底座；没有明确文字目标时可跟随世界中的紫色任务指引。排除左侧固定任务提示、顶部状态区和底部技能区，同时保留屏幕右侧边缘入口。

以角色脚下为基准，按 W/A/S/D 八方向短步移动；默认足点为画面 `(0.51,0.58)`，单步 `0.18秒`。可调足点、步长；到达附近不再持续沿同方向走。物体落点是二维近似，具体触发范围需实机校准。

确认活动场景且连续两张新截图出现敌人血条时，进入单人通用战斗：普通攻击并向敌方血条下方估计位置移动，默认每2秒轮流尝试 `e,q`。按活动实际键位调整“通用战斗技能键”，支持 e/q/r/t；清空时只普攻。截图中的拟形技能与普通角色大招不混用角色专属逻辑。低血量目标继续追踪，持续掉血也算有效进展。

默认移动时穿插普攻，以击碎可破坏岩石。持续无进展时先尝试原地破障，再侧移；仍无进展停止并报告。默认每阶段8秒，不会无期限顶着岩石走。这是局部接近策略，不是完整地图寻路，不能保证绕过所有不可破坏障碍。

### 目标替换与停止

同位置名称变化、旧目标消失、新物体出现时，先释放旧输入，重新取得连续新帧确认。不会把物体消失记为领取完成或通关；本任务不产生整场完成记录，仍可右键任务卡保存证据。

失去活动 HUD、目标不明或页面切换时停止输入；30秒仍无确认目标则停止任务，提示检查结算/教学/交互页面。当前只处理靠近触发的物体，不对未知选择框、确认框或消费按钮自动提交。

只向前台游戏输入。每个短步后释放按键，保持期间每25毫秒检查停止/暂停/焦点；切出后等待，返回后重新识别，不补发积累的动作。输入后端异常仍逐个尝试释放已按下的键。

### 验证边界

使用用户提供的七张截图，遮盖顶部性能统计和底部特征码后制作1280×720回放样本。覆盖活动页、敌人血条、紫色标记、远处奖励、共鸣因子、行动资金、金色入口、右边缘绿色藏宝地入口；模拟不同分辨率和同位置新目标；菜单负例与输入清理另行验证。

图像和 OCR 固定在1280×720处理，相比2560×1440输入像素数减少75%，相比3840×2160减少约88.9%；这不是总CPU或总耗时同比下降的承诺。完整发现每0.7秒一次，已选物体使用局部文字复查。

尚未操控用户设备完成实际移动、破障、拾取或整场通关。离线通过不能替代实机验证，足点、血条下方偏移和物体触发范围仍需实际游戏确认。
