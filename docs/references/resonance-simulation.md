# 群声共振模拟域自动战斗（1.86.01）

入口：任务 → 活动 → 群声共振模拟域。玩家手动进入活动、移动、选择奖励和前往下一关；启动任务后，程序只负责战斗。活动结束时手动停止任务。支持简体中文、16:9 画面。

## 战斗与暂停

程序连续两帧识别到右下角 E、Q 技能键帽后，持续短按普攻，默认每 2 秒尝试一次 E。键帽按固定图样匹配，兼容亮色地面下变浅的文字。只有 Q 图标外围的完整黄色充能圆环连续两帧成立时才尝试 Q。是否自动战斗只取决于技能栏，不检测敌人或角色血条；技能栏消失、打开菜单或切换页面时停止输入并等待。

在任务设置的“Combat Toggle Key”中选择 `/?`、`鼠标侧键1` 或 `鼠标侧键2`，然后启动任务。旧配置没有这个字段时默认使用 `/?`；修改设置后重新启动本任务才会切换绑定。任务状态和日志会显示本次使用的按键。

按一次所选按键可暂停自动战斗，再按一次继续。`/?` 是键盘上 `/` 与 `?` 共用的物理键，按住 Shift 不影响识别。侧键1通常是鼠标“后退”键，侧键2通常是“前进”键；以设备实际输入为准。若鼠标驱动已把侧键映射成键盘按键，系统可能不会再上报侧键1/2，此时应恢复鼠标侧键的原始功能。任务不接受其他自定义按键。

独立采样线程每 20 毫秒检测一次按下边沿；按住不重复切换，松开后再按才再次切换。只有游戏或 OK-WW 窗口在前台时接受切换，其他程序在前台时忽略。手动暂停时立即释放任务按住的攻击和技能输入。任务状态会显示“自动战斗中”“等待技能栏”或“已手动暂停”。

打包版配置的 WGC 截图与 PostMessage 输入支持游戏在后台时继续识别技能栏，并将攻击消息发给游戏窗口。使用其他输入方式时仍等待游戏回到前台。程序自身暂停、手动暂停、技能栏消失或任务停止时释放已按下的键和鼠标按键；恢复后需再次确认技能栏，不补发积累的动作。任务不会自动寻路、锁敌、切换角色、点击奖励或判断整场通关。

## 设置与验证边界

“Skill Interval”设置 E 的尝试间隔，范围 0.5–10 秒，默认 2 秒。“Combat Toggle Key”只提供上述三个选项。Q 的释放取决于完整充能圆环，不按固定间隔无条件触发。

离线回归覆盖亮暗活动画面、720p/1080p/1440p 缩放、遮盖血条后仍能识别技能、菜单负例、Q 满环与非满环、三个绑定选项、短按边沿、后台输入方式判断及输入释放。鼠标侧键的实际硬件上报和游戏中的切换效果需在打包版上验证。
