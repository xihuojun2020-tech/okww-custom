# 群声共振模拟域自动战斗（1.85.02）

入口：任务 → 活动 → 群声共振模拟域。玩家手动进入活动、移动、选择奖励和前往下一关；启动任务后，程序只负责战斗。活动结束时手动停止任务。支持简体中文、16:9 画面。

## 战斗与暂停

程序连续两帧识别到右下角 E、Q 技能键帽后，持续短按普攻，默认每 2 秒尝试一次 E。键帽按固定图样匹配，兼容亮色地面下变浅的文字。只有 Q 图标外围的完整黄色充能圆环连续两帧成立时才尝试 Q。是否自动战斗只取决于技能栏，不检测敌人或角色血条；技能栏消失、打开菜单或切换页面时停止输入并等待。

按键盘上的 `/ ?` 共用物理键可暂停或继续本任务。按 `/` 或按住 Shift 输入 `?` 都使用同一虚拟键码，与字母大小写无关。独立采样线程每 20 毫秒检测一次按下边沿，减少截图和战斗循环漏掉短按的机会。游戏或 OK-WW 窗口在前台时接受按键，其他程序在前台时忽略。任务状态会显示“自动战斗中”“等待技能栏”或“已手动暂停”。

打包版配置的 WGC 截图与 PostMessage 输入支持游戏在后台时继续识别技能栏，并将攻击消息发给游戏窗口。使用其他输入方式时仍等待游戏回到前台。程序自身暂停、手动暂停、技能栏消失或任务停止时释放已按下的键和鼠标按键；恢复后需再次确认技能栏，不补发积累的动作。任务不会自动寻路、锁敌、切换角色、点击奖励或判断整场通关。

## 设置与验证边界

“Skill Interval”设置 E 的尝试间隔，范围 0.5–10 秒，默认 2 秒。Q 的释放取决于完整充能圆环，不按固定间隔无条件触发。

离线回归覆盖用户提供的亮暗活动画面、720p/1080p/1440p 缩放、遮盖血条后仍能识别技能、菜单负例、Q 满环与非满环、短按边沿、后台输入方式判断及输入释放。打包版 1.85.01 的 2026-09-23 日志显示亮色场景下频繁在“自动战斗中”和“等待技能栏”之间切换，切走游戏时则显示“等待游戏回到前台”；本次修改分别处理这两个原因。更新后的实机后台战斗仍需验证。
