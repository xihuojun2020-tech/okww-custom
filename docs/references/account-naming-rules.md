# 账号命名与配置规则

适用版本：1.50.06，更新日期：2026-09-10。

## 显示名称

统一格式为“编号-游戏昵称-手机号”，列表默认脱敏，例如 `A5-测试昵称-199****0005`。编号、昵称、完整手机号是三个独立字段，不要把整串名称填入新建窗口的编号栏。

“当前序列账号”逐行显示 `【编号-昵称-脱敏手机号】`，每日账号、当前执行账号、测试目标、旧序列选择及任务状态的账号字段也显示这些要素，刷新后不退回短编号。日志和持久化仍保留原有安全标识。

界面按 UUID 或完整旧名称优先匹配，短编号必须唯一。若资料无法读取或未填写，显示“未填昵称/未填手机号”；编号有歧义则提示“账号匹配不唯一”，不会猜测另一个账号的资料。NAS 离线不影响从本机账号仓库解析，但本机缺失的资料不会凭空补齐。

账号编号使用一个英文字母加数字，例如 A1、A5、B10。新建窗口建议未占用的 A 系列编号，可手动更改；重复编号不能创建。昵称可包含连字符，解析旧名称时使用第一个编号与末尾手机号作为边界。

## 新建账号

1. 填写账号编号、游戏昵称和 11 位完整手机号。
2. 查看实时显示名称预览，确认三者对应同一个游戏账号。
3. 按需填写备用登录识别名称与游戏内特征码，勾选所属序列。
4. 确认创建。同手机号已有账号时会提示，但不会自动合并；重名/身份有歧义可能导致运行时安全校验拒绝切换，请先核对。

新建账号内部保存短编号和独立身份字段，UUID 是账号稳定标识。昵称与备用登录识别名称是不同字段，不能相互替代。

## 现有账号整理

仅从严格符合“编号-昵称-完整手机号”的旧名称补齐空的昵称、完整手机号和脱敏手机号字段。已有资料与旧名称冲突，或识别身份被其他账号占用时，跳过该账号，不覆盖冲突值。

执行前核对清单，保存账号级备份；写入经过已有账号仓库发布流程和版本冲突检查。中途出错即停止，已完成项可在再次预检查后跳过，不重复覆盖。

旧名称键为兼容历史引用保留。UUID、序列成员及顺序、任务计划、备用识别名与完成记录不因显示名称改变。已有错序不会自动猜测恢复。

## 隐私与修改

下拉框、序列列表、账号标题和新建预览默认显示脱敏号码。账号识别信息内可勾选“显示完整手机号”，切换账号后自动恢复隐藏。手动显示完整号码或在输入栏输入时，请勿截屏上传。

普通任务配置保存不能修改身份字段。身份修改仍使用明确的重新绑定流程；未开放的身份字段应通过受控资料维护处理，不直接改 UUID 或配置文件。

本说明不包含真实完整手机号。真实账号配置与备份只保留在本机，不随源代码推送 GitHub。
