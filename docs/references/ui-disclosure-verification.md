# 1.45.00 UI 验收记录

## 范围

本轮以 1.44.00 的五页平铺结构为基础，增加按需展开并精修共享 Qt 控件，不重写任务执行或更换框架。

| 区域 | 本轮处理与验证 |
| --- | --- |
| 任务/活动/测试 | 共用 ConfigCard 参数折叠、运行操作常显、刷新状态不折叠；实际每日、多账号、周本元数据渲染；活动/测试空态渲染 |
| 通用设置 | 快捷键与低频选项折叠；配置跳转展开祖先；连接和更新操作常显 |
| 日志诊断 | 连接设置按需展开；状态和保存、重试不隐藏；空目录定位字段 |
| 账号 | 只读身份、体力周本、其他选项、高级操作折叠；表单重绘保留展开状态；错误提示定位 |
| 序列 | 收起保留真实账号顺序摘要；展开后列表自然高度，无内层滚动；维护状态常显 |
| 新账号/模板/JSON/长文本 | 共享字段与弹窗主题；中文操作按钮；可调整编辑窗按屏幕限制初始尺寸 |
| 状态浮窗、完整性、运行确认、程序偏好、角色代码 | 保留既有交互与安全边界；沿用共享主题，已有相关 UI 回归覆盖。未声称每个辅助弹窗均完成独立真机截图验收 |
| 主窗口 | 限制最小尺寸与恢复位置至可用屏幕；测试非主屏坐标和小逻辑屏幕 |

## 技能应用

- Frontend Design：保持白/灰/蓝的已确认方向，以层级和留白组织内容，不引入宣传页面、在线字体或装饰动画。
- UI UX Pro Max：本地检索 `accordion keyboard focus`，应用焦点可见与不遮挡、渐进展示、表单反馈原则。没有 Qt 专用栈，不套用网页或手机尺寸。
- Web Design Guidelines：2026-09-09 从 `vercel-labs/web-interface-guidelines` 主分支源码包读取 `command.md`（raw 域名解析失败时的官方源回退），应用原生按钮、标签关联、键盘操作、明确动作、错误定位和内容溢出检查。没有将检查描述为 WCAG 认证。

## 可复现验证

```powershell
Copy-Item -Path custom_ok/ok/* -Destination .venv/Lib/site-packages/ok -Recurse -Force
.\run_tests.ps1 -Group all
$env:QT_SCALE_FACTOR='1.5'
$env:OKWW_UI_EXPAND_ALL='1'
.\.venv\Scripts\python.exe scripts/render_flat_ui.py tests/output/ui-1.45/1.5-expanded
```

渲染矩阵：100%、125%、150%、200% DPI，760×700 和 1100×800 页面逻辑尺寸；默认收起和全部展开各一轮。80 组主页面检查均无可见子滚动条或页面横向溢出。另渲染新建账号和模板窗口。截图使用合成账号、模拟设备与无操作回调，未执行游戏任务。

截图目录：`tests/output/ui-1.45`；文档示例见本目录的 `flat-ui.md`。
