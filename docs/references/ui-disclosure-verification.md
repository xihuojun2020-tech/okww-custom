## 技能应用

- Frontend Design：保持白/灰/蓝的已确认方向，以层级和留白组织内容，不引入宣传页面、在线字体或装饰动画。
- UI UX Pro Max：本地检索 `accordion keyboard focus`，应用焦点可见与不遮挡、渐进展示、表单反馈原则。没有 Qt 专用栈，不套用网页或手机尺寸。
- Web Design Guidelines：2026-09-09 从 `vercel-labs/web-interface-guidelines` 主分支源码包读取 `command.md`（raw 域名解析失败时的官方源回退），应用原生按钮、标签关联、键盘操作、明确动作、错误定位和内容溢出检查。没有将检查描述为 WCAG 认证。
