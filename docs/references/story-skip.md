# 剧情跳过：六边形图标（1.82.03）

启用已有“剧情自动跳过”任务即可使用，无需额外配置。

1. 在非正常大世界页面，匹配原有跳过图标或新增六边形图标。
2. 后台任务通过连续新帧确认后点击图标，等待出现“剧情梗概”。
3. 同时匹配中央“剧情梗概”标题与下方右侧“跳过剧情”，再经新帧确认点击右侧按钮。左侧“继续观看”不会作为候选。
4. 如果启动时梗概页已经打开，也能直接处理。普通任务的阻塞式剧情确认共用同一识别方法。

另一种页面是“完整观看剧情更有助于了解故事发展，是否确认跳过？”提示。程序同时核对剧情提示、登录不再提示文字和右侧确认按钮，先点击文字前的白色圆圈。取得新截图并识别圆圈内的勾选标记后，进入独立确认阶段，再点击右侧确认。已勾选时不再次点击圆圈；勾选状态不明则等待，不走通用确认。后台圆圈阶段最多点击一次，60 秒未完成则按原有导航超时处理；点击丢失不会连续切换圆圈。梗概页后出现此提示也按同样顺序处理。

新增图标只在画面顶部左右角查找，包含完整六边形轮廓而非仅内部三角形。旧模板阈值不变；新增图标阈值 0.85，梗概标题 0.85，跳过文字 0.88。图像按高度 720 等比例缩放，模板缓存；无需全屏 OCR。

新增确认模板基于简体中文截图；其他语言继续使用已有识别能力。用户补充了点击前的完整截图，已验证黑边下方左上角入口，以及右侧相似图标不被识别为跳过。真实未勾选提示页也已验证；勾选后的白圈黑色标记使用合成样本测试，仍需实机确认实际样式。当前不根据图标消失推断剧情已成功跳过，保留原有页面切换核验、超时与重试上限。

1.82.03 验证范围：剧情识别测试扩展为 17 项，覆盖真实图标全屏图、真实梗概页、真实未勾选弹窗的四种分辨率，以及已勾选、状态不明、点击丢失、梗概转提示、普通任务勾选确认。另运行旧确认、后台导航、新帧确认、测试注册及发布检查。原有宽屏截图测试因本地素材缺失而跳过。
