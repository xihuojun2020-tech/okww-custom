# 每日优先级与材料目标（1.97.11）

## 每个账号的执行顺序

1. 开头领取已完成小任务积分，读取实际活跃度和180体力任务进度。
2. 战歌重奏：仅游戏日周一执行、周日独立复核。北京时间04:00换日，其余日期跳过。
3. 残象聚落与梦魇聚落：核对并完成该账号勾选的全部地点；列表为空则跳过。旧总开关保留数据，执行只看列表。
4. 世界首领材料：按三个目标顺序累计成功领奖；全部达标自动关闭。下一轮用“新增次数”输入还要领多少次。
5. 体力用途：凝素、无音区、旧模拟领域或“无”，沿用该账号原选项。
6. 所有已选耗体力任务结束后，领取积分及宝箱，在同一次页面访问中复核活跃度。

最终实际活跃度达到100才标记每日完成。低于100直接报错交给用户处理，不自动补刷或整账号重跑；识别未知也不标记完成。未选聚落本身不代表活跃度不足。

中途只有准备转换备用体力时允许复核活跃度；按缺项转换经过验证的最小金额，不使用星声、月相或溶剂。每日缺项优先于材料目标；已确认的当前体力可继续刷取。

## 设置凝素目标

在账号配置中选择“体力用途＝凝素领域”，然后填写最多两组领域及本轮还需刷出的金、紫、蓝、绿数量。程序不读取培养目标或背包库存。

绿色当量为 `27×金 + 9×紫 + 3×蓝 + 绿`。80体力估算50当量，40体力估算25当量；余量至少50且当前体力足够80时用双倍，其他仍有需求且体力至少40时用单倍。

例如还需10金、3紫、2蓝、4绿，合计307当量，预计6次80体力和1次40体力。实际掉落可能不同，最后一次允许估算超出需求；这里记录的是已经核验的体力消费对应的估算产量。

每次确认领奖扣除后累计进度，跨天保留，账号之间隔离。完成第一组后执行第二组；全部完成后自动刷该账号配置的无音区。无音区持续使用当前体力，直到不足或用户改变选择。

修改本轮数量沿用进度；点击“新一轮”或更换材料领域后，从零累计新轮次。新账号模板复制需求，不复制目标轮次及进度。尚未填写目标的旧凝素账号继续沿用旧刷法。

## 异常领取核对

领奖意图会先保存，再点击领取。发生中断且无法确认实际扣除时，保留待核验事件，暂停该账号后续体力消费。停止任务后，在凝素设置中核对该次实际消耗为0、40或80体力，再继续运行。

配置包导入和备份恢复合并领取事件，不覆盖已经确认的消费，也不丢失待核验记录。旧账号的选择及旧开关值保留。

## 验证范围

本次发布包含自动流程、进度持久化、配置往返及界面验证。真实游戏中的OCR、地图进入、战斗实力和材料掉落仍需后续运行日志确认；自动测试不代表所有账号的实机整日流程已经通过。
