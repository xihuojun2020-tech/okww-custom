# 1.56.00 账号、任务与完成检查使用说明

实施依据：用户确认的桌面文档《OKWW界面与账号配置调整方案-2026-09-11.md》。早期聊天中的残缺方案不作为需求。此说明同时记录本次修改边界，供后续维护接续。

## 页面分工

- 任务：选择序列、账号或执行起点，开始、暂停和停止任务。
- 账号：编辑账号计划、待办提醒和录像设置；管理账号序列。
- 完成检查：只读查看运行记录、已有完成时间和图片证据，手动保存截图。

三个页面不是三份独立账号数据。显示名称继续含编号、昵称和手机号要素，底层使用原 UUID 和序列顺序。单账号每日任务选序列只筛选账号，不执行整条序列；多账号功能执行选中的序列。备用识别名仍复用原账号配置数据源。

## 待办提醒

在账号配置展开“待办提醒”，可选择活跃度、残像聚落、周本、每周乐园、活动1、活动2、活动3，点击确认保存。旧账号默认未设置。

勾选只表示需要关注，不是任务开关，也不是完成标记。全部勾选或取消均不改变自动流程、体力分配、周本检查和失败补跑。提醒独立绑定 UUID，不修改真实执行参数。活动1/2/3不随活动区排序而绑定不同活动；本版不提供自定义名称。

完成检查的账号标题附近显示提醒；“仅看提醒项目”默认关闭。取消提醒不会删除证据。手动截图项目中的活动1/2/3与这些固定提醒 ID 对应。

## 任务入口与活动

每日任务展开后保留序列、账号和备用识别名；多账号保留当前序列、起始/继续账号、当前序列成员。账号列表按保存顺序展示，例如 A4 → A1 → A3 不会重新排序。原有任务配置仍然生效，详细参数请到账号页编辑。

清弦纪流年沿用原弹琴任务逻辑、配置和 `piano_activity` 历史证据，不会因为改名重置参数。若梦仍有回声、群声共振模拟域显示“待实现”，无开始按钮、不发键鼠输入、不参加每日调度、不产生成功记录。可展开后手动截图。

活动排序使用代码中显式的功能更新序号；最近功能更新靠前，同次更新固定次序。修改账号参数、运行任务、保存图片、安装解压时间都不影响排序。只变更显示顺序，不改变任务注册索引。

账号与工具沿用整行展开、默认折叠。设置行和分组留白缩小，移除重复边框；仍保留必要的身份说明、错误提示、保存状态及删除确认。

## 录像留档

在账号配置展开“录像留档”。支持的四页固定全部选中且不可取消：任务页、每周乐园、战令、残像聚落。总开关和时长仍可按原行为设置，不强制开启录像。

旧部分范围在下一次用户确认保存该账号时，先创建原配置备份，再存完整范围。未保存旧账号运行时也使用完整范围。编辑器在旧账号缺少录像字段时读取当前每日任务的既有设置，不用新默认值覆盖有效的总开关和时长。升级本身不会批量改写真实账号。

打不开的页面、有异常或没有有效帧的页面如实记录，不能算录像成功。录像文件名增加微秒，减少同秒运行覆盖风险；历史文件不随入口迁移删除。完成检查仅链接新运行明确记录的本地 MP4 路径，失效路径提示不可用，不猜测其他录像的账号归属。

## 运行、完成与证据

完成检查的“运行记录”默认折叠，展示最近运行范围、开始时间、结束时间、结果和各项目已有完成时间；周本单独执行与完整每日任务明确区分。

- “正常返回”只说明代码流程返回，不表示所有项目都完成。
- “执行出错”“已停止”反映该次运行结果，不修改失败重试逻辑。
- 没有结束记录时显示“未记录结束（结果未确认）”，不假定仍在运行或已经成功。
- 旧数据缺少开始/结束时间时显示无记录；已有完成时间只作完成记录，不生成伪造图片。

开始记录从账号确认与配置校验之后建立；在此之前失败不会伪造已执行的账号记录。写入失败只报错，原任务返回值、异常和完成判断不变。新记录存于本机证据仓库，不依赖 NAS；不会根据文件时间扫描导入旧录像。

## 手动留证与永久保留

在任务卡片右键选择保存证据，或进入完成检查点击保存当前画面。程序先冻结游戏窗口图片，再打开确认框；账号初始为“请选择账号”，不能直接沿用正在浏览的账号。选择归属、项目和状态并确认后才能保存。

采集时运行绑定只作提示。选了其他账号时需再次确认；最终账号标为用户确认，同时保留原运行 UUID。选择不会登录/切号，取消不保存；自动留证仍使用原可信绑定，不弹出此对话框。

截图原图、缩略图和说明继续永久保留，不按日期、数量、空间或任务成功自动删除；回收区不自动清空。手动移入回收区后，仍需再次明确确认才能永久删除。

“备份证据”备份图片及 SQLite 索引（包括运行记录），不会把仓库外的 MP4 文件复制进去。需要完整保护录像时，请另外备份录像目录。NAS 下线不影响本机查看已经保存的证据。

## 验证与后续边界

验证使用临时账号仓库、模拟输入与合成截图，不修改真实账号、不中断用户游戏。覆盖提醒隔离和脏草稿、序列稳定、录像备份及固定范围、手动归属冲突、运行结果透明性、保存失败不干扰执行、旧证据保留、活动展示及注册不变。

具体测试结果见更新日志和 `docs/superpowers/plans/2026-09-11-account-ui-desktop-plan.md`。真实游戏、跨设备录像路径和安装包仍需现场验收；占位活动自动化、提醒自定义名称和录像远端同步不在本次范围内。
