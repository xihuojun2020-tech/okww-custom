# 无序列：未登记账号独立执行

在任务页“当前账号”面板的账号下拉选择“无序列”，允许未登记账号执行独立任务，不读取特征码。切换序列或刷新下拉时保留这一选择；选择已注册账号后恢复原有严格核验。

以下入口必须选择注册账号并通过身份验证，不能使用无序列：多账号每日任务、多账号每周乐园、每日任务、海墟、深塔。拦截发生在任务开始前，不自动选择其他账号或退出登录。

无序列执行时清除旧账号绑定和备用体力授权，不读取旧账号方案、不自动写入其次数、进度、完成记录或证据。共享自动战斗偏好和恢复逻辑不变。

- 天工寻物：本次运行保存内存状态，六关仍按实际最高款项跳过或挑战；下次通过游戏成绩续跑，不建立注册账号存档。
- 初露峥嵘：正常试用、领奖和核验游戏状态，不自动记录注册账号完成。
- 周本独立入口：使用显式选择的周本；“按账号刷取任务执行”在无序列下没有账号方案，改为游戏列表首项。依照游戏本周剩余次数执行，不累计到任何账号。
- 首领突破材料独立入口：使用当前任务选择的首领和本次领取次数，复用生产领奖确认逻辑和本轮内存计数；不读取每日方案，不授权备用体力，不写注册账号累计。

## 验证

覆盖五类强制入口启动前拦截、免认证不调用特征码核验、旧绑定/备用授权清理、子任务旧绑定不能写证据、序列切换保留无序列、临时存档不落盘、材料领奖重复确认不重复计数，以及周本/材料绕过每日账号流程。

实际游戏中未登记账号的战斗和领奖仍需更新后验收。
