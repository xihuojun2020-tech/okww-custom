# 1.59.00 养成材料规划与收益统计

## 开启与运行

在“账号配置 → 体力”中开启 **养成材料规划**，保存该账号后运行每日任务。默认关闭，不批量改写既有账号。首版支持简体中文、16:9 游戏窗口；账号身份仍使用现有验证与 UUID 绑定。

流程：首次/每周一 04:00 后首次运行扫描 B → 资源仓库 → F2 培养目标 → 计算十组四档缺口 → 按武器类型与材料预览选择凝素 → 领取并完整扫描收益 → 返回刷新培养目标。每次领取后复核；接近目标时只领取一次体力。确定凝素材料满足前再扫仓库及刷新目标，之后按既有无音区设置刷声骸。每日预算用完不追加声骸消费，下次运行继续。

周本设置有“自动（列表首项）”、指定周本、“无”三种含义：未指定默认自动；自动读取游戏列表首个周本，不能识别则停止。已存的“无”保持关闭。周本依旧走现有每周检查流程，并不与凝素仓库统计混用。

## 如何判断材料已够

- 保留绿、蓝、紫、金四档真实数量；仅把本档需求之外的剩余以 3:1 向上合成，不向下、不跨组。
- 绿色等价 = 绿 + 3×蓝 + 9×紫 + 27×金，仅用于显示总量和统计，不能独立决定完成。
- 通用转化道具不纳入字典可用库存；“可补齐”不代表刷完。
- 培养页显示的当前持有量用于刷新仓库快照后的变化；不能将没看到或没识别的材料当作零。
- 共鸣者突破材料只记录；技能升级材料为周本材料，只显示培养页读数；已经确认的怪物材料排除体力刷取。
- 图标字典收录 40 个凝素模板及给定样本中的两组怪物素材。遇到其他尚未确认的培养素材行，会保存证据并停止消费，待增加真实模板后支持。

## 收益统计口径

一次领取可有多张图。程序回顶后向下滚动，按相邻画面的行位置与图标/数量对应拼接，只消除画面重叠，不消除不同位置的相同奖励。

目标组绿色格子数就是奖励份数：绿 7 与绿 6 两格是 2 份，合计绿 13；不是 13 份，也不按截图张数或体力/40 计算。不检测活动、不对页面数量再次倍乘。300 黑金圆环按未知/经验证据保留，不记为贝币。

给定两张图回放结果：22 格，目标绿13/蓝16/紫3/金0，2份，绿色等价88；用户提供的80体力对应每份44、每体力1.1。真实运行的体力取现有领取确认结果，不从活动标签推算。

累计统计只使用完整结算的最新解析修订；缺帧、数量不明或绿色目标缺失不会进入均值。每份、每体力均值用总量除总份数/已知体力总数，不平均各记录的比率。均值暂不控制自动刷取。

## 永久数据与导出

默认目录：`%LOCALAPPDATA%\OKWW\MaterialPlanner`，其中 `index.sqlite3` 为索引，`assets` 为不可覆盖 PNG。无自动删除策略，账号删除或目标切换不会级联删除材料资料；更新包也不覆盖此目录。原图保存在运行设备本地，不会随版本发布上传 GitHub。

程序运行信息中显示缺口、仓库校准、周本/突破需求和累计收益。关闭程序后可在源码目录用以下命令读取同一份数据：

```powershell
.\.venv\Scripts\python.exe -m src.materials accounts
.\.venv\Scripts\python.exe -m src.materials stats --profile "账号UUID"
.\.venv\Scripts\python.exe -m src.materials export --profile "账号UUID" --output "E:/材料明细.csv"
.\.venv\Scripts\python.exe -m src.materials backup --output "E:/材料备份-20260912"
```

导出文件、备份目录必须是新路径。CSV 包含领取 ID、品质、数量、位置、解析版本和证据目录；备份含 SQLite 与原图。可用 `--root` 读取另一份备份。保留备份而不覆盖历史文件。

## 手动验收

用户于 2026-09-12 明确选择自行实机验收。本版本完成离线验证并交付；下列操作未宣称实机通过。

1. 单账号启用，确认 F2 培养目标与 B 资源仓库导航正确，滚动扫描覆盖仓库计数，右侧旧选中详情不串到其他格子。失败应停在原页面并留图。
2. 查看同一武器类型两代材料是否分开；可补齐但实际不足仍显示缺口；金有余但绿不足不能判完成；突破材料不足不阻塞凝素完成。
3. 分别领取40、80体力；绿色目标格子数分别随实际奖励列表计份。活动四份待活动时补验，不设置活动模式。
4. 多图收益确认重叠行只记一次，不同格子的相同物品都记；最后一次领取也保存；确认不完整时不点击再次挑战。
5. 停止后检查数据仍在，重启后累计不重计；更换账号各自独立。每周一校准未完成不记为完整周快照。
6. 材料够后复核仓库与目标，再按预算转无音区；周本自动项选择实际列表首项，指定项与“无”仍按各自含义执行。

失败反馈请保留对应材料目录及当次日志，说明账号短名、时间、停留页面；不要删除原始证据。单份、四份、零库存、新目标和其他怪物素材组合是优先补充的真实样本。
