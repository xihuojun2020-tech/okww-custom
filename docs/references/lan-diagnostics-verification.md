## 修复的验证发现

1. 通用手机号脱敏会误改摘要/随机 ID 中的数字：生成的协议标识按格式验证后保留，消息文本继续脱敏。
2. 初始封装偏移会错过最后一张后帧：worker 将错误窗口截止时间作为独立唤醒时刻，不依赖普通一秒采样的相位。
3. GitHub 既有版本的测试加载依赖包旧执行器：测试子进程通过导入器加载仓库 custom_ok，不修改 site-packages、不跳过失败测试。
4. 1.54.01 将 CI 测试与打包依赖装入独立虚拟环境，解决运行器预装工具的依赖冲突。
