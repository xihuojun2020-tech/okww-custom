# 完成检查使用说明

适用版本：1.60.00。

## 查看与截图

进入“完成检查”，左侧按序列或名称选择账号。这里只改变展示，不登录或切换游戏账号。账号显示编号、昵称和遮罩手机号，历史已删除账号仍以停用账号展示。

右侧可查看当前检查、分页历史和回收区；点击图片打开原图，支持适应窗口、原始大小和复制图片。新截图会替换当前展示；未知状态的新图显示待核验，不继承旧图的确认结果。日/周内另有明确记录时，单独展示其时间与来源。没有图片不等于未完成。

当前检查分为三组：每日更新包含活跃度、残像聚落、战令；每周更新包含周本、每周乐园；新截图更新包含四项活动、深塔、海墟、矩阵。跨周期只切换展示范围，不删除旧截图，也不代表自动打开游戏截图。

当前活动统一为“若梦仍有回声”“群声共振模拟域”“清弦纪流年”“第二索拉·诡影迷踪”。账号待办提醒按同样三组提供 12 个项目；已配置的旧活动提醒仍显示为待归类，可以取消旧项并勾选正式项目后保存。不自动猜测旧活动对应关系，历史证据保留。

## 复制图片到微信

在截图卡片点击“复制图片”，或右键卡片/预览选择“复制图片”；打开原图后也有同一按钮。复制成功后切换微信，在聊天输入框按 Ctrl+V 粘贴。

复制的是原图像素，不是缩略图、文件路径或整张界面卡片。每次复制一张，支持当前与历史图片。原图缺失或无法读取时提示失败并保留已有剪贴板内容，复制不改变截图账号和完成状态。

本版不自动发送微信消息。未来按账号 UUID 绑定指定收件人，例如 A1 绑定 A1 的微信联系人；该发送功能、收件人核验和自动发送授权尚未实现。

手动进入需要留证的游戏页面后，点击“保存当前画面”，或右键相应任务卡片选择“保存当前画面为证据”。仅截取游戏窗口，不发送按键，不自动跳转页面。归属初始为“请选择账号”，必须明确选择具体账号，再选择项目、状态和备注并确认保存。采集时运行绑定只作提示；选择其他账号需额外确认，保存最终用户归属与原运行绑定。采集期间切号、窗口不可用或超时会拒绝请求。预览冻结后不随切号更换图片，弹窗取消不保存。

账号标题附近显示独立待办提醒，“仅看提醒项目”默认关闭。运行记录详情默认折叠，开始/结束时间、正常返回/错误/停止与已有完成时间分别展示；正常返回不代表全部完成，旧数据缺少时间显示无记录。新录像仅按运行时明确记录的路径关联。具体规则见 [1.56.00 说明](account-ui-1.56.md)。

默认“待核验”；主动选择“已完成”等状态后记录为“手动确认”，不会修改每日任务完成标记、失败重试记录或任务断点。修改结论时重新保存一条证据，旧记录仍保留。

## 每日收尾截图与录像

账号配置的“截图与录像”分组提供独立开关。“每日任务后截图”默认开启；旧账号没有该字段时同样默认开启，保存账号时才持久化用户设置，不在升级时批量改写真实账号资料。原录像开关和时长继续保留。

- 推荐只开截图：完成日常后、退出账号前，依次打开任务页、每周乐园、战令、残像聚落，每页保存一张到完成检查，不创建 MP4、不等待录像时长。
- 同时开启录像：同一次访问每页先截图再录像，不额外遍历；截图与录像都关闭则跳过这次收尾巡检。关闭此开关不取消任务过程中原有的活跃度/周常/周本结果留证。
- 活跃度与周常乐园按正在保存的同一帧识别；战令、残像聚落及识别失败页面标记待核验。每日任务正常结束不能作为所有项目完成的证据。
- 页面打开失败提示具体页面并继续其他页面；录像不可用仍尝试后续截图。截图提交、异步保存失败分别记录，未保存不能写成成功。
- 停止后不追加导航或截图，视频写入器仍释放。已提交的图片由后台保存，元数据和画面已经冻结，不会因开始下一个账号而串号。

## 自动采集范围

| 项目 | 本版行为 |
| --- | --- |
| 活跃度 | 按现有 OCR 结果保存对应帧，100 分达标；不声明奖励已领取 |
| 周常乐园 | 已识别周常目标积分达标时留证；不声明已领奖 |
| 周本 | 奖励剩余次数为 0 时记已完成；复核仍剩余时记录部分完成及原因 |
| 残像聚落、战令 | 每日收尾自动截图为待核验；也可手动留证，未实现完整结果自动判定 |
| 深塔 | 手动留证，未实现完整结果自动判定 |
| 清弦纪流年、第二索拉、海墟、矩阵、若梦仍有回声、群声共振模拟域、活动1/2/3 | 手动留证；按键次数、运行时间不作为完成依据 |

自动留证要求本轮有可信账号 UUID；未绑定的独立任务不会猜测所属账号。自动保存失败不阻断任务、不重新消费体力；磁盘允许时保存无图记录，否则提示保存错误。队列最多容纳 4 次保存，满时提示本次未保存。应用异常被强制结束可能留下待整理文件，不会自动删除。

游戏日按北京时间 04:00、游戏周按周一 04:00 划分；周日补检仍属于同一个游戏周。战令按每日展示采集记录，不据此推断整期战令全部完成。活动、深塔、海墟、矩阵保持最新截图，直至保存更新的截图；较旧截图补传不会覆盖新图。

首次访问旧证据库时，残像聚落与战令的旧周期索引会先备份至 `backups/daily-periods-独立编号/index.sqlite3`，再按原采集时间归入游戏日。该备份为迁移前索引快照，原图片和不可变 JSON 原始说明留在原处；现行查询使用数据库中的已迁移元数据。时间无效的记录保留历史并提示，不猜测周期。普通“备份证据”仍可制作包含图片的完整备份。

## 永久留存、删除与备份

Windows 默认目录：`%LOCALAPPDATA%/OKWW/CompletionEvidence`。每台设备独立，不依赖 NAS，不自动上传。UUID/项目/周期目录下保存 PNG 原图和缩略图，SQLite 保存索引，JSON 保存关联说明。

所有已保存截图长期保留，不按时间、数量或空间自动清理，不覆盖旧图。账号删除、周期过期、补跑成功、升级、通用日志清理均不删除证据。空间不足只报错，不删旧图腾空间。

“移入回收区”仅隐藏记录，原图仍在；回收区不会自动清空。永久删除需要到回收区另行确认，删除明确选中的原图、缩略图和说明，不改变任务完成记录。已生成的备份不联动删除。

“检查存储与空间”只读统计主仓库占用、缺图、孤立/临时文件数量；孤立文件保留待人工整理，不猜归属、不自动修复或清除。数据库损坏会显示操作错误，不覆盖为新空库。请保留整个目录再安排修复。

“备份证据”将一致性索引和已索引图片复制到仓库 `backups/独立编号/`，不轮换清理。主仓库空间统计不含备份；备份会额外占用空间。需要异盘保护时关闭程序后自行复制完整仓库目录。恢复前保留现有目录，不直接覆盖。

本版只读展示已有完成时间，不将旧时间戳转换为图片证据；不扫描导入旧录像或无可信元数据图片。每日截图与录像入口位于账号配置，页面固定全选；录像开关、时长和历史录像保持。证据备份含运行索引但不复制仓库外的 MP4，录像需要单独备份。未提供批量删除、远端同步或未知活动的自动判定。真实游戏、异机安装和安装包构建需现场验证。
