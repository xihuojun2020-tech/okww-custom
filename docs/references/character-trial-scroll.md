# 1.60.03 角色试用横向拖拽扫描

1.60.03 将底部头像的移动方式改为横向拖拽：使用框架 swipe 接口，按检测到的头像间距拖动一格，持续0.5秒，纵坐标固定在头像中心。左右方向均通过实际位移确认，至少两个头像唯一匹配且位移一致才接受结果。停止或输入异常时释放鼠标。活动入口左侧列表仍使用纵向滚轮。

新增横向距离、重叠范围和异常释放回归测试，角色试用单元测试32项通过。未操作真实游戏，本版仍需安装后验证头像条实际接受拖拽；不能将离线测试视为现场问题已经闭环。

## 1.60.02 响应观察机制（本版保留）

修复针对初露峥嵘角色试用的头像扫描。滚动前在已识别头像中心悬停0.15秒，发送一格滚轮后观察响应1.5秒；每次稳定视图读取另有2秒上限。稳定旧位置不会立即结束等待。每方向最多三次尝试，扫描整体90秒上限（正在进行的取帧或OCR结束后检查）。

确认位移后继续原来的左右边界扫描、唯一重叠合并和逐角色选择。仍有截断头像且滚动无响应时仍然停止，不能把报错消失当成完整扫描，也不会以固定头像数量伪造成功。角色选择使用相同的滚动观察逻辑。

日志可检索“头像滚动观察”和“头像滚动已确认”，包括方向、尝试、位置及位移。最终异常继续走现有角色试用故障截图流程。本版没有更换PostMessage输入后端，也没有加入未经实机验证的拖动降级。

## 已完成验证

- 30项角色试用单元测试，包含延迟运动、第二次输入恢复、持续无响应、页面变化、停止、扫描时限和原有流程保护。
- 3项实图识别测试通过；这些是已有截图的离线测试，不代表实际滚动验收。

## 安装版验收

1. 更新并重启实际安装版，在关于页面确认1.60.02或后续包含本修复的版本。
2. 在游戏活动页运行角色试用，确认先扫描全部角色，未遮蔽右侧截断角色。
3. 若仍然报错，保留本次日志、故障原图和“头像滚动观察”记录。若两个方向连续三次位移均为零，需要进一步实测PostMessage输入响应；不要继续增加滚动次数或放弃完整性验证。
4. 分别验证初始左端和右端、停止操作、已完成角色不重复进入、待领奖角色正常领奖。
