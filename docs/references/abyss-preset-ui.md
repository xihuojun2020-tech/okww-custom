# 深塔新版预设编队（1.97.03）

打开周期挑战、选择逆境深塔、点击深境区“前往”、进入三座塔与选择关卡仍使用原流程。点击“挑战开始”后，程序确认“角色列表／预设编队”和“开启挑战”，再切换到预设编队页。

程序逐页识别游戏中实际保存的三人预设，包括成员顺序和每名角色的**当前疲劳值**。卡片上的箭头左侧是当前值，右侧是本关结束后的预计值；分配和续关账本只使用左侧。头像或数值无法确认、预设不完整、主角形态无法确认的预设不参与分配。新版预设页不显示角色等级，因此使用用户已保存的预设，不再从这一页推断等级。

疲劳值识别包含完整箭头区域，结合OCR块位置区分当前值和预计值，要求至少两次裁剪读数一致；箭头漏识别时仍可核对左侧完整数值，拒绝矛盾和没有箭头的孤立0。右侧预计值及闪电误识别成的15／45不计入当前疲劳值。当前疲劳为0、未知或成员不在可用账本的预设会被排除，其他完整合法预设仍可分配。日志会显示所有识别到的预设角色和疲劳值，等级未知不会隐藏账本。

分配器只从已识别的完整预设中选队，仍考虑三塔优先顺序、跨塔共用疲劳值及每层消耗。不再合成页面上不存在的替补或自由编队。点击选定预设后复核下方三个头像与顺序，再点击“开启挑战”；续关再次出现编队页时也会复核，必要时重新选择同一预设。无法复核时截图并停止输入。

两侧塔可以同时开放多层；扫描接受“已完成前缀→连续可挑战楼层→锁定后缀”。第4层选中边框和数字圆圈会分别核验，数字圆圈与锁模板冲突时改为逐层按钮核验。真实状态冲突或12星与逐层证据不一致仍会重扫并标记未知。

总12星布局及实际楼层证据已确认时，完整核验四层，不因第4层数字漏识别而只规划前三层。已选择的真实预设若能支付同侧全部剩余楼层，则保持这支队伍并同步后续计划；1、2、3、4层分别消耗1、2、3、4点，初始10点正好打一整边，前三层后剩4点应继续第4层。实际不足仍重新编队或结束，下一座塔重扫实际疲劳。中塔仍按两个属性区段处理。

主角元素取卡片内的真实图标，排除金色选中边框和背景。下方头像没有元素图标：以头像确认主角身份，再用选中卡片的元素和对应选人编号核验形态，不根据下方背景颜色猜光／风／暗主。

“两侧塔优先”按残响→回音→深境运行；任一侧状态未知，已确认的另一侧仍可挑战，中塔暂缓且不进入共享疲劳分配。两侧状态明确、已完成或确实无法继续时，再按原分配规则处理中塔。“中间塔优先”仍按深境→残响→回音。1.97.04起，当前入口存在体力足够、无逆属性输出的顺属性完整预设时，先限定当前关使用这类预设，再规划剩余楼层；不为了跨塔累计评分把该队拆分留给另一侧或跳过当前关。没有该候选时保留全局层数和兜底分配。状态未知不会被当作疲劳不足或已完成。

选人编号的裁剪包含完整方框并放大OCR，容忍左侧行号定位偏移；仍要求对应编号、成员顺序和主角形态全部匹配。回音塔第三层真实失败截图已离线确认，错误主角形态仍拒绝。
