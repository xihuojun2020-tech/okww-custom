# 深塔新版预设编队（1.97.02）

打开周期挑战、选择逆境深塔、点击深境区“前往”、进入三座塔与选择关卡仍使用原流程。点击“挑战开始”后，程序确认“角色列表／预设编队”和“开启挑战”，再切换到预设编队页。

程序逐页识别游戏中实际保存的三人预设，包括成员顺序和每名角色的**当前疲劳值**。卡片上的箭头左侧是当前值，右侧是本关结束后的预计值；分配和续关账本只使用左侧。头像或数值无法确认、预设不完整、主角形态无法确认的预设不参与分配。新版预设页不显示角色等级，因此使用用户已保存的预设，不再从这一页推断等级。

疲劳值识别包含完整箭头区域，要求至少两次裁剪读数一致；不会把右侧预计值或闪电误识别成的15／45计入当前疲劳值。当前疲劳为0、未知或成员不在可用账本的预设会被排除，其他完整合法预设仍可分配。日志会显示所有识别到的预设角色和疲劳值，等级未知不会隐藏账本。

分配器只从已识别的完整预设中选队，仍考虑三塔优先顺序、跨塔共用疲劳值及每层消耗。不再合成页面上不存在的替补或自由编队。点击选定预设后复核下方三个头像与顺序，再点击“开启挑战”；续关再次出现编队页时也会复核，必要时重新选择同一预设。无法复核时截图并停止输入。

两侧塔可以同时开放多层；扫描接受“已完成前缀→连续可挑战楼层→锁定后缀”。第4层选中边框和数字圆圈会分别核验，数字圆圈与锁模板冲突时改为逐层按钮核验。真实状态冲突或12星与逐层证据不一致仍会重扫并标记未知。

“两侧塔优先”按残响→回音→深境运行；任一侧状态未知，已确认的另一侧仍可挑战，中塔暂缓且不进入共享疲劳分配。两侧状态明确、已完成或确实无法继续时，再按原分配规则处理中塔。“中间塔优先”仍按深境→残响→回音。分配器仍先考虑总可打层数，再考虑优先塔层数，可能为总层数保留队伍；状态未知不会被当作疲劳不足或已完成。

当前周期属性如下：

| 塔与楼层 | 顺属性 | 逆属性 |
|---|---|---|
| 残响之塔 | 气动 | 导电 |
| 回音之塔 | 湮灭 | 冷凝 |
| 深境之塔 1—2 层 | 导电、热熔 | 冷凝、湮灭 |
| 深境之塔 3—4 层 | 无 | 衍射 |

“开启挑战”后的地图、战斗、结算及“继续挑战”沿用现有流程。2026-10-04本机2560×1440截图离线回放验证了两个完整预设的六个当前值均为10，以及两侧八层分配。不同分辨率的重采样小字可能仍无法确认，此时跳过该预设，不猜成0。完整实机挑战仍需验收。
