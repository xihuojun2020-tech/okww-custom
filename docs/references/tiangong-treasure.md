# 天工寻物：最高难度与账号续跑

## 使用

先打开游戏的天工寻物六关列表，在程序任务页选择对应已注册账号，再运行“天工寻物”。开始核验读取当前画面右下角特征码；未绑定、重复绑定或与所选账号不一致时明确停止，不退回主界面。

不在名单上的账号可在“当前账号”的账号下拉选择“无序列”。此模式不读取特征码，不写入注册账号存档或完成记录；本轮按游戏实际成绩执行，下次仍可通过最高款项跳过已达标关卡。需要保存账号进度时，请登记特征码并选择该注册账号。

任务按见习札记Ⅰ～Ⅵ依次检查。最高款项达到80000的跳过，未解锁的本轮跳过，未达标且已解锁的每轮打一次。结算点击“确认挑战结果”返回，主动选择下一关；低分不会原地反复重打，下次运行再补打。

难度菜单按位置点击，与当前按钮文字无关。唯一最高难度核验是推荐等级90。三个试用头像上的队伍数字决定是否加入队伍，允许3、1、2，白色边框不算选中。使用共享自动战斗，原地先找F开启挑战，没有才短距离前进。

## 存档

运行数据的logs/tiangong_progress/<账号稳定ID>.json保存各活动期六关的状态、实际最高款项、核验时间及最近挑战时间。文件使用已有原子写入接口，每关立刻保存；账号和活动期分别隔离，修改昵称、重启和代码升级不改变存档归属。

启动和结算返回后均从游戏成绩复核，存档中的“打过”不代表达标。如果在结算后保存前中断，下次在关卡页读取成绩补齐。读不到成绩不会当作0；真实OCR漏掉孤立0时，必须识别到单独的0字形才记零分。

截图沿用okww监控室，完成证据沿用tiangong_treasure本期。六关全部达标才自动标已完成，未解锁或未达标保留部分完成。原手动保存画面按钮仍按用户选择默认标已完成，不改游戏存档。

当前任务仅支持16:9中文游戏画面，从关卡页开始；不自动打开活动入口，不领取未提供流程的活动奖励。截图/离线验证不等于实机战斗验收。
