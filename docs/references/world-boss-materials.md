# 世界首领突破材料：三目标累计领取

适用版本：1.95.07。用于常规世界首领角色突破材料。素材获取中选择“讨伐强敌”，复用周本的关卡搜索和挑战导航，战斗继续复用4C流程。

进入地图后核对首领血条。海之女使用实际全名“海之女·荣光的灰烬”，支持相邻同一行等级/名称被OCR拆开；不能核对到正确目标时不领取奖励。任务结束或异常退出会清理本任务临时战斗状态，可重新开始。切人被游戏拒绝且目标头像灰色、提示无意识恢复物品时，暂时跳过该队友继续战斗；复苏后恢复可切入。自动战斗启用设置只由用户手动关闭。

## 设置

打开账号设置，选择对应账号，在“日常与声骸”中找到“世界首领突破材料”。新账号模板也可预设三行。

| 优先级 | 首领目标 | 累计领取上限 | 执行规则 |
|---|---|---|---|
| 1 | 选择名称 | 填入0至9999整数 | 未达标时先刷 |
| 2 | 选择名称 | 填入0至9999整数 | 第一项目标达标后刷 |
| 3 | 选择名称 | 填入0至9999整数 | 第二项目标达标后刷 |

“无”或上限0跳过该行；三行不能重复选择同一首领。旧账号升级后默认全部关闭，需自行选择目标和次数后保存。

填写的是历史累计目标：已领取6次，想再领取3次，应把上限填9。次数跨日、跨周、账号改名、换序列及程序重启保留；降低上限不会降低实际累计次数。

## 每日执行顺序

1. 单账号或多账号每日读当前已核验账号的配置及累计进度。
2. 在原体力用途前，按优先级刷尚未达标的首领。
3. 按名称及同行按钮定位首领，战斗前核对血条名称。
4. 战后寻找选中的F“领取奖励”交互，每轮只领一次单倍奖励。
5. 核验费用及实际体力扣除，保存累计次数；本次材料产出4个还是5个不影响计数。
6. 当前目标达标后当次切换下一首领。
7. 三目标全部达标后，继续本账号已设置的无音区、凝素领域、模拟训练；启用材料规划的账号继续材料规划分支。

体力不足时保留累计及当前未完成目标，下一次从剩余次数继续。备用体力沿用现有每日活跃度授权，仅在已确认缺项且策略允许时补齐；不会为了累计目标无限提取备用体力。

## 单独执行与测试入口

1. 在“任务 → 每日执行 → 每日任务”选择对应序列及当前账号，手动登录这个游戏账号。
2. 展开同一区域的“世界首领突破材料”任务卡，在“首领关卡”选择要刷的首领，在“领取次数”填写本次次数（1至9999，默认1次）。
3. 点击开始，核对确认提示中的游戏账号、首领和本次领取次数。
4. 此入口只刷本次选择的首领；实际成功领取达到设置次数或体力不足时结束，不转刷其他体力用途，不自动切换账号。

该入口会实际消耗体力、领取材料，与单账号、多账号每日共用同一UUID及累计账本。无需修改账号三目标计划；每日首领目标未启用或已经累计达标，也可单独执行。比如选择“云闪之鳞”、3次，就是本次成功领取3次；不是把账号历史累计上限改成3。

成功领取会减少账号每日计划的剩余需求，但本次选择不改写每日目标或上限。死亡、复活、战斗失败及未实际领取不计次。若设置3次而体力只够1次，结果显示本轮领取1次并结束；下次启动按届时任务卡填写的新次数执行，已确认的账号累计继续保留。

启动确认后直接进入素材获取的“讨伐强敌”，不读取或领取每日活跃度条目。此独立入口只用当前体力，不自动提取备用体力；体力不足时结束。每日任务中的三目标分支仍沿用每日活跃度授权。不执行周本、乐园、每日奖励收尾或每日留档，不写入整套每日完成。任务卡显示首领关卡、领取次数、大招及治疗切换设置。启动后固定本次关卡和次数，运行中修改任务卡仅影响下次启动。

关卡搜索使用与周本相同的滚轮及右侧滚动条兜底。确认目标及同行“直接挑战”并点击后，支持两种画面：若进入详情，则复核目标名称、处理剧情前往确认，再点击“单人挑战”；若直接到编队，则同时识别“快速编队”和“开启挑战”，直接继续开始。加载期间开启挑战只提交一次。若按钮是“前往/传送”，继续原有地图传送及寻路流程。

完成检查的运行记录标为“首领材料单独执行”，并继续展示同一账号的累计目标。停止或异常后恢复账号绑定与运行策略，保留已确认累计及未确认领奖事件。

## 核对与校正

“已领n/上限”由同一账号UUID的账本提供，单账号和多账号不会分开计数。完成检查的运行记录区域也展示累计状态。未来累计目标未达标，本身不会把已完成的本日活跃度标为失败。

若领奖界面、扣除结果或保存结果未知，程序保留“待核验”事件，拦截该账号后续体力消费，避免重复领取。处理步骤：

1. 停止当前任务。
2. 查看日志及okww监控室证据，确认这次是否实际领取。
3. 到账号设置点击“核对未确认的材料领取”。
4. 选择“是”计入一次；“否”确认未领取；“取消”保持待核验。
5. 全部待核验事件处理后，必要时点击对应首领“校正”，录入真实累计次数。

无法确认时保留待核验，之后取得证据再处理。成功领取后退出界面失败，已经保存的次数仍然有效。
