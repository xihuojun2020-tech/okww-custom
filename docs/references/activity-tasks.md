# 任务分类与活动辅助

适用版本：1.52.00。

## 入口

- 任务 → 每周任务 → 自动深塔：原工具入口迁移，战斗逻辑与配置不变，不会自动加入每日流程。
- 任务 → 活动 → 弹琴教学：原工具入口迁移，原有识别和按键参数保持。
- 任务 → 活动 → 第二索拉·诡影迷踪：新增持续 F 键辅助。

沿用统一卡片与右侧独立开始按钮；有参数的卡片默认折叠、整行展开，新活动没有额外设置，不增加空的折叠面板。工具页不再重复展示已迁移项目。

## 第二索拉·诡影迷踪

1. 手动进入游戏活动界面。
2. 点击该任务的开始按钮，并将游戏切到前台。
3. 程序持续短按 F，按下到下次按下约 0.85～1.15 秒，按住 50～100 毫秒，均为小范围随机值。
4. 活动结束后手动停止，或随时使用原有暂停/停止控制。

切出游戏期间不继续发送按键，也不会主动抢前台；恢复前台后继续，不补发积累的按键。游戏窗口丢失时停止。按键操作退出或异常时尝试释放 F，暂停/停止可能等待当前不超过约 100 毫秒的短按结束；系统调度可能影响实际耗时。

此功能只按 F，不识别地图、选项或活动是否结束，也不承诺随机间隔可以规避游戏检测。请仅在需要持续 F 输入的活动界面启动。未通过真实游戏验证的部分不得表述为已经实测。
