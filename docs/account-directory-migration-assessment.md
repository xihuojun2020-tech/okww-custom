# 每账号独立目录迁移评估

日期：2026-08-25  
结论：**NO-GO，当前版本不迁移真实配置。**

## 评估范围

候选布局把 `account_master_config.json` 投影为一个 `index.json` 和 `accounts/<profile_id>.json`。账号文件保存账号元数据、任务配置、计划和扩展；索引保存全局版本、时区、序列与根扩展。运行完成记录继续位于独立运行状态目录，不进入账号配置。

`src.account_directory_assessment` 仅在内存中完成投影、往返和风险检查，不创建目录、不修改真实配置。

## 阻塞项

- 现有完整性校验、接受指纹、配置包清单和事务回滚均以单一 master 文件为原子边界。
- 多文件发布需要事务日志、崩溃恢复、部分写入回滚和并发修订检查，尚未完成故障注入验证。
- 必须先证明旧版可无损读取新布局、降级可恢复到原 master，并处理重复身份与未知扩展字段。
- 备份和配置包格式需要明确账号文件清单及每文件摘要，否则可能形成“索引已更新、账号文件未更新”的混合版本。

## 后续 GO 条件

只有在临时目录完成双写试运行、断电/进程终止故障注入、旧版回滚、配置包往返和逐账号恢复测试后，才重新评审。满足前继续以 UUID 键控的单一 master 为权威来源。
