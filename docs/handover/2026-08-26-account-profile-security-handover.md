## 已完成

1. 每个账号使用独立 UUID 文件：`configs/accounts/profiles/<UUID>.json`。
2. `index.json` 只保存账号索引和序列成员关系；序列成员使用 UUID，不使用可变显示名。
3. 账号身份分三层保存：
   - `masked_phone`：带星号手机号，是当前切换时的首要识别依据；
   - `alternate_login_name`：通常为 `U...A` 的扫码备用识别名；
   - `game_feature_code`：游戏内防 OLED 烧屏遮罩区域的稳定特征码，目前只读记录和展示，不参与任务。
4. 账号编辑器写入草稿后通过 CAS 修订检查发布；修改 A1 的 JSON 不会直接覆盖其他 UUID 文件。
5. 发布服务先写完整临时 bundle，再生成 SHA-256 manifest，最后原子替换 `active.json`。
6. 每日任务和多账号每日任务通过账号仓库读取已校验的 active 快照；快照存在但校验失败时安全停止，不回退到半写入的可变总配置。
7. 账号删除仍为二次确认、备份、移除序列引用、删除账号运行状态的级联操作；序列删除只删除序列本身。

## 运行目录

```text
configs/
├─ accounts/
│  ├─ profiles/<UUID>.json
│  ├─ index.json
│  └─ sequences.json
└─ published/
   ├─ bundles/<revision>/
   └─ active.json
```

`active.json` 是运行时入口，不要手工编辑。账号编辑、序列编辑和导入流程必须通过仓库/发布服务完成。

## 安全边界

- 未识别到唯一的带星号手机号、备用识别名或严格要求的特征码时，不得猜测账号；任务应停止并等待人工确认。
- `game_feature_code` 当前不能由普通账号编辑页写回，也不能改变现有切换行为。
- 运行进度和完成记录继续按 UUID 分离保存，禁止写入其他账号配置。
