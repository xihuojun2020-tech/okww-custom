## 统一组件规范

### 任务卡片

收起时：左侧 Fluent 图标；中间名称和一条简短说明；右侧短状态、开始按钮、展开箭头。名称与说明可换行，右侧操作不能被压出页面。紧凑头部目标高度约 72–84 个逻辑像素，但不用固定高度裁切长文本。

展开时：标题与详情同一背景和外边界，仅内部细分隔；参数默认左侧名称和帮助、右侧控件。窄窗口根据可用宽度改为上下排列。长文本行全宽显示，重置等次要操作位于详情底部。

说明优先采用现有任务 description，只有明确的摘要需求才使用现有配置值生成短摘要；不复制调度逻辑或推断“已完成”。周本账号配置只提供编辑跳转，不在任务卡片复制编辑器。

### 展开与操作

- 首次创建所有可折叠区域均收起；分类标题本身不折叠。
- 标题区文字、图标和空白点击均切换展开；按钮、开关和箭头有各自独立事件。
- 详情区点击和编辑不能触发收起；允许多卡片同时展开。
- 普通状态刷新保留展开和用户输入，不触发 enable/disable；继续屏蔽程序化开关同步信号。
- 诊断定位或显式跳转允许展开目标并滚动到可见位置。
- 键盘可到达操作按钮和展开箭头，焦点可见；无功能参数的卡片不显示无效展开箭头。

### 视觉尺度与主题

- 使用 Segoe UI／微软雅黑，正文 13–14、标题 15–16、页标题约 20 个逻辑像素；遵守系统缩放。
- 页面边距 20–24、卡片间距 8–12、分组间距 16–20；去掉多层 SectionPanel 累积的大块空白和重复分隔线。
- 浅色、深色、跟随系统三种主题；使用框架现有主题配置，不另建第二份主题偏好。保留可识别的既有选择，无有效选择时跟随系统。
- 单一强调色配中性背景；状态颜色只表示成功、警告、错误。浅深色均校验正文对比度至少 4.5:1。
- 统一 Fluent 图标，展示层替换装饰性 Emoji；不修改任务类名、配置键或持久化标识。
- 只保留轻量悬停、按下、展开反馈；无模糊背景依赖、循环装饰动画或大幅页面动效。

## 页面规划

| 页面 | 结构与边界 |
| --- | --- |
| 任务 | 保留每日、每周、声骸、活动分组；小分组标题加连续任务卡片，不再套一层大卡片 |
| 账号 | 页内“账号配置／账号序列”切换；保留原编辑实例，切换不重建草稿；当前账号和保存区域明确可见 |
| 自动辅助 | 顶部紧凑全局运行控制；下方辅助卡片使用开关，参数在内部展开；不创建第二个执行控制器 |
| 工具 | 诊断、备份恢复、完整性、实验功能分别为卡片；最近结果与主要操作收起时可见，危险动作继续确认 |
| 设置 | 游戏连接、运行按键、外观偏好、通知、更新分组；现有设置和更新服务复用，不增加同义入口 |

账号页按身份信息、每日计划、周常计划、收尾行为折叠。周本选择与次数记录继续按账号存储。离开或切换账号时沿用现有草稿保护，不能因页内切换静默丢弃编辑。

自动辅助页将全局运行状态和功能启用意愿分开。自动战斗头部显示“手动保持开启”或“异常恢复中”，详情显示等待时间及最近异常，不因主题或控件刷新重新建立保护。

工具页展示最近日志上传结果和上传操作；更新卡片展示当前版本、来源及检查结果。未知状态必须显示未知，不以绿色成功状态代替。完整日志进入独立查看区域，不在任务列表常驻嵌套日志窗。

## 滚动与数据流

一页一个主要纵向滚动区域，卡片按展开内容自然增高。继续提取子页面内容而不是嵌套滚动容器。账号页内两个标签分别只有当前内容参与布局。超长日志可在独立查看窗口滚动。

数据流保持：既有任务/服务状态 → 卡片摘要和按钮；用户点击 → 既有任务操作或配置服务；配置修改 → 现有验证与保存。布局、主题、状态刷新不得反向产生任务操作。窗口缩小时先换行和重排，不隐藏必要操作、不依赖横向滚动。

## 分阶段交付

1. 任务页样板：先实现任务卡片的整体外观、说明行、内部表单、紧凑分组，输出真实控件离线截图，覆盖收起、展开、运行和错误状态。先不移植账号页结构、不改变全局主题默认值；局部样式作用于样板卡片，公共行为回归覆盖其他使用者。
2. 样板确认后统一主题和公共组件，检查所有页面的潜在影响；不同时维护两套正式卡片组件。
3. 迁移自动辅助、账号、工具、设置，保留原服务与编辑实例；迁移完再清理不再使用的旧样式。
4. 完成完整回归、浅深色与缩放验收，更新说明、交接、更新日志与截图记录，按仓库版本规范发布。

本轮设计文档不改程序版本、不创建版本标签。后续代码发布以届时实际 config.py 为基线进行版本递增，避免抢占其他任务的版本；首次改版按中等改动递增第二段。

## 验收清单

- 真实任务元数据无遗漏或重复；周本、活动等原分类和隐藏规则不变。
- 逐一验证标题、空白、开始、暂停、停止、开关、箭头、详情编辑点击；状态刷新不触发手动启用入口。
- 760/1100 内容宽度，100%/150%/200% 缩放，浅色/深色；检查文字、按钮、焦点、卡片边界、滚动和展开状态。样板先验证局部外观，最终阶段覆盖完整主题切换。
- 多账号草稿、保存/放弃、序列切换、任务跳转以及诊断错误提示均有回归；原自动战斗保护专项继续通过。
- 使用项目本地虚拟环境、隔离测试运行器和真实页面离线渲染；不启动游戏、不输入真实账号，不上传测试诊断或发布 NAS 包。
- 文档明确区分离线截图、自动化测试、真实游戏实测、Git 推送与安装器构建状态。

## 设计审核结论

范围限于 UI 与必要的展示状态适配，业务执行、周本调度、体力顺序、账号事务、上传更新后端均保持。首个交付点为任务页样板，不将全程序重构和样板验收混为一次完成。本文审核通过后编写执行计划，再实施样板。
