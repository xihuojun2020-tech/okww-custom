# 自动深渊 16:9 分辨率兼容设计

## 目标

自动深渊在打包到不同电脑后，支持任意不低于 1280×720 的标准 16:9 捕获分辨率，重点覆盖 1280×720、1600×900、1920×1080、2560×1440 和 3840×2160。

## 方案

- 继续使用现有 0～1 归一化区域和点击坐标，不维护分辨率坐标表，也不把画面统一缩放到 1080P。
- 任务在发送第一个游戏操作前检查当前捕获帧：帧必须存在、宽高至少 1280×720、宽高比与 16:9 的误差不超过 0.02；失败时截图、显示明确错误并停止。
- 角色头像模板高度直接按捕获高度的 10.5% 缩放，仅保留适配最低 720P 的安全下限，避免 720P 模板被强制放大到原来面向较高分辨率的 96px。
- 局部数字 OCR 改为按目标高度缩放并限制最大倍数：低分辨率小裁剪放大，高分辨率裁剪不再固定放大 3～4 倍，降低 4K OCR 开销。
- 周期挑战、完成和锁定模板继续按 `frame_height / 1440` 缩放，现有逻辑已经适配任意 16:9 高度。

## 错误边界

- 非 16:9、低于 720P、空帧或异常帧一律在任务入口停止，不进入 F2，不点击游戏。
- 本次不承诺宽屏、黑边、非等比拉伸、系统缩放导致的非客户区裁剪，也不增加自动改游戏分辨率逻辑。
- OCR 或模板在真实设备仍失败时保留现有阶段截图，不降级为盲点固定坐标。

## 验证与发布

- 用 720P、900P、1080P、1440P、4K 合成帧验证比例区域、角色网格、安全点击、滚动条、头像模板和 OCR 缩放。
- 验证非 16:9、低于 720P 和空帧在任何操作前停止。
- 只运行离线测试，不启动或操控游戏。
