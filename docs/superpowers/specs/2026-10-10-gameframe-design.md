## 目标与完成定义

独立框架提供可实际执行的插件加载、任务调度、帧服务、设备输入、视觉工具、状态记录、停止与清理、CLI 和桌面启动器。鸣潮游戏包可完整接入当前 22 个一次任务、7 个触发任务、57 个角色相关源码文件及账号／材料／证据／界面／诊断／更新业务。游戏包可独立构建；不靠原 checkout 的绝对路径运行。57 包含基类和工厂，不等于 57 个专属角色脚本。

所有现有功能迁移必须有实现路径与验证证据。游戏业务先兼容接入，之后逐层迁移到独立运行核心；阶段状态分别记录为“兼容保留”“独立实现”“离线通过”“实战未验证”，四项不互相替代。新增框架不导入 ok、src、qfluentwidgets；旧运行时和旧游戏业务留在 AGPL 兼容包。

## 已选择架构

Python 独立核心与执行器，PySide6 普通控件启动器，游戏包使用素材＋声明式配置＋必要专用模块。现有 Python 业务和测试规模支持这个选择；今晚引入 C# 业务重写没有足够迁移收益。以后若测量表明需要，采集热点可换为原生模块而不改变游戏业务接口。

主控与执行器分进程。主控只管理包、任务、配置和生命周期；识别→决策→输入链在设备所在会话内执行，不每帧走主控 IPC。一个执行器只运行一个活动输入任务。实际业务未确认完成则不保存为 success。

游戏包 manifest 包含 id、version、api_version、entrypoint、license、platforms 和 task 列表。任务包含 id、title、kind、default_config、required_capabilities。manifest 检查发生在外部包边界；内部确定的数据不重复校验。

源包导入只加载其入口模块，入口不得初始化设备。独立任务调用 GamePackage.run(task_id, TaskContext)。兼容包通过明确的 legacy 启动入口承接原应用与全部原 UI，保留授权义务。完整程序入口与游戏包入口共用生产 bootstrap，避免第二套账号／登录／战斗实现。

## 接口与职责

| 模块 | 职责 |
|---|---|
| gameframe/api.py | Frame、Action、Device、TaskContext、GamePackage |
| gameframe/packages.py | 本地包发现、manifest、任务索引、独立入口加载 |
| gameframe/runtime.py | 单一输入执行、停止、失败记录、最后清理 |
| gameframe/state.py | 框架自己的运行记录；不另造鸣潮业务账本 |
| gameframe/vision.py | 无游戏知识的区域、模板、颜色工具 |
| gameframe/devices/ | 离线帧、Windows HWND WGC、输入、MuMu 多触点及通用 ADB 后端 |
| gameframe/controller.py | 执行器进程生命周期；只管理自身进程 |
| gameframe/worker.py | 包任务入口和结构化状态输出 |
| gameframe/gui.py、__main__.py | 桌面与 CLI 启动器；加载元数据不启动游戏 |
| gamepacks/wuthering_waves/ | 原程序完整兼容包、任务索引、资源与配置归属 |
| scripts/build_gamepack.py | 可复现自包含包构建与内容校验 |

Frame 序号只表示该帧源的新帧。captured_ns 必须说明 timestamp_source，不能把主机收图时刻说成游戏产生时刻。采集结果按最新帧处理；消费者拥有其返回 image 的有效期，不能在异步识别中使用可能被覆盖的 view。

Action 支持 PC key_down/up、button_down/up、相对镜头，以及 Android touch_down/move/up(contact)。后端分别声明能力，不假定单次 click 可以覆盖摇杆＋攻击。设备失败抛出真实错误；新帧尚未到达可返回 None。

自动战斗启用意图与当前可执行状态分开。暂时无图、设备失败、恢复 hook 错误不清除偏好；只显式关闭自动战斗才写入 disabled。当前游戏包继续共用原生产战斗 loop，禁止新增并发输入者。

## 设备选择

PC HWND 采集优先 windows-capture 的 MIT Python bridge，独立后端延迟导入；普通相对／键鼠输入在对应会话内使用。PostMessage 保留为游戏特定后端。Python Frame.crop 是 CPU裁剪，首版不得宣传 GPU ROI回读已实现。DXcam WinRT monitor 后端不替代 HWND遮挡捕获。

MuMu 是首个 Android 后端，原生像素与有 contact 的持续多触点可降低组件数。雷电原生截图＋MaaTouch作为第二路线；未实施部分要明示。SDK动态加载用户已安装组件，不随包附带厂商DLL；商业授权仍待确认。

Child Session 首先验证当前身份的原神公开路线，鸣潮未验证。新的论坛/issue证据表明输入法重定向可能干扰主桌面，因此不能无条件承诺键鼠隔离。系统配置与游戏会话测试在本轮禁止范围内；只实现有证据的接口和宿主入口，不在测试里启用会话。
