# 功能分类整理（用户已确认）

常用导航为任务、账号、自动辅助；底部导航为工具、设置。

- 任务：每日执行、每周任务、声骸获取与整理、活动。分组标题不折叠，任务详情默认折叠；空组不显示。
- 账号：账号识别、日常与声骸、清理体力、周本挑战、周常安排、收尾行为、高级账号操作与序列。保存/丢弃/草稿提示常显。
- 自动辅助：复用唯一运行控制，分战斗与拾取、剧情与移动、登录与输入；不因迁移自动启用。
- 工具：日志诊断、数据备份、导入恢复、完整性、实验功能、开发诊断。实验任务不晋升为稳定任务。
- 设置：游戏连接、运行与按键、程序偏好、版本更新；合并原辅助程序设置，不恢复关于。
- 账号计划只有一个编辑入口，任务选择器与只读摘要保留，管理按钮跳转账号页面。
- 不改变任务注册、可见性、周本顺序、账号事务或安全确认。旧路由映射新页面。页面只有单层滚动。
