# 群声共振模拟域实施计划

用户已批准本任务直接执行；在当前会话逐项完成。

**Goal:** 手动进入活动后，以可配置关键词和紫色标记导航，用单角色通用攻击清敌，移动中破障。

**Architecture:** 独立 ResonanceSimulationTask 复用 BaseWWTask 截图/OCR 和现有输入后端。纯图像与目标选择在 resonance_simulation.py；不调用普通 AutoCombatTask，不锁敌、不转镜头、不切角色。

**Tech Stack:** Python 3.12 本地 .venv、OpenCV、现有 OCR、unittest。

**Spec:** 本会话批准的方案：关键词包含/精确匹配与优先级、阶段约束、角色脚下到物体落点的八方向短步、连续新帧确认、目标替换重识别、失去证据停止输入。

## 约束

- 手动进场启动，中文、16:9；不自动消费、选择未知弹窗或宣称整场完成。
- 仅游戏前台输入；每次输入限时，暂停/停止/异常释放；无进展限次破障、侧移后报错。
- 左侧固定任务栏、顶部 HUD、底部技能/教学文字不能当世界目标；屏幕边缘世界物体仍可检测。
- 降采样图像定位；任务栏与目标 OCR 降频，位置仍从当前帧验证；不同物体不复用旧动作。
- 发布遵循 AGENTS；只提交本任务文件。
