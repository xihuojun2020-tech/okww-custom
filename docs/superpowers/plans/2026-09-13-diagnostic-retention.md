# 诊断资料保留期限实施计划

目标：本地上传成功满 24 小时后清理；NAS 未检查包保留 30 天；完成检查和报告归档后保留原包 3 天，报告长期保留。

- [x] 增加诊断包清理模块：使用现有 FileLease、safe_path 和 SHA256；本地仅清理已关闭、全部上传成功的会话。活动会话和未传成功数据保留，清理回执保留。
- [x] 增加 AI 检查交接命令：必须提交非空 Markdown 报告及原包 SHA256，先持久化报告，再转移诊断包、提交检查完成标记。中断可重试，不能把打开文件当成已检查。
- [x] NAS 未检查计时从上传成功开始；已检查计时从检查标记提交开始。只处理有协议回执的项目诊断包，不按任意文件修改时间删除。
- [x] 程序启动及运行中每小时在后台执行清理，NAS 操作放入有超时的子进程，不恢复自动上传。两台设备共享 NAS 清理锁。
- [x] 测试 24 小时/3 天/30 天边界、上传失败、活动会话、缺报告、报告被改、越界路径以及重复执行。
- [x] 更新界面文案、AI 工作区交接规则、执行文档和版本；发布记录见执行文档及对应版本标签。

限制：程序都关闭或 NAS 不可达时，清理在下次程序运行且 NAS 可达时补执行，不能声称 NAS 自身已有定时服务。旧散文件不伪造已检查状态，另行按完整批次协议识别处理。
