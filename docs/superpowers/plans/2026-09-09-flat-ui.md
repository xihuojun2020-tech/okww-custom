# Unified flat desktop UI Implementation Plan

**Goal:** 五个主页面统一为浅色、平铺、单层滚动界面。

**Architecture:** 保留 PySide6、QFluentWidgets 和业务回调。普通内容使用 QWidget/QVBoxLayout，只有顶层 Tab 拥有页面滚动；复杂文本在独立对话框编辑。复用 ConfigContentMixin 的配置绑定与条件字段逻辑。

**Tech Stack:** Python / PySide6 / QFluentWidgets / unittest。

**Spec:** 用户于 2026-09-09 确认的六阶段 UI 改造方案（本任务上一条设计答复）。本任务内顺序执行，无新增依赖或子代理。

## Global Constraints

- 不改任务执行顺序、账号存储、身份保护、诊断与更新业务。
- 保留用户现有 docs/reviews 删除记录，不纳入提交。
- 框架覆盖文件必须位于 custom_ok，版本 1.44.00。
- 主内容最多一条纵向滚动条，短选项平铺；长文本允许独立详情窗口滚动。

## Implementation checklist

- [x] 公共布局：SectionPanel / FlatSettingRow / CodexTheme；普通 ConfigCard 不再继承滚动卡片，保留配置联动；TaskTab 使用自然高度布局。
- [x] 通用设置：快捷键内容脱离内层 Tab；采集与交互方式使用平铺单选；诊断操作集中；日志与版本单独分区。
- [x] 任务、活动、测试：统一任务标题与说明、操作栏、状态；去除重复外框及过期说明。
- [x] 账号：统一设置行，JSON 独立编辑并保留取消语义；主要与低频操作分开；模板对话框单层滚动。
- [x] 验证：新增真实 Qt 控件树、动态尺寸、选择回调及 JSON 取消测试；运行现有账号、导航、配置、周本与发布测试。
- [x] 视觉：使用临时账号和模拟设备在离屏窗口渲染，不触发游戏控制、生产账号写入或网络操作；检查 100/125/150/200% DPI。
- [x] 文档与发布准备：更新版本、更新日志、程序结构、交接、UI 使用说明；更新包构建与校验完成。GitHub 分支/标签及 NAS 发布由本任务执行最终回读确认。
