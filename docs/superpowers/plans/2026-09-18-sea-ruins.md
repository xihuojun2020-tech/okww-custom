# 冥歌海墟 Implementation Plan

> Execution: 本会话按用户明确要求直接逐项实施；复用已有任务接口，不新增依赖。

**Goal:** 完整使用预设编队自动完成再生海域7—11层，匹配可用信物并核验上下半转场。

**Architecture:** `sea_ruins.py` 负责纯数据、周期规则和组合评分；`sea_ruins_vision.py` 负责标准化截图及几何识别；`AutoSeaRuinsTask.py` 负责有界状态流程与输入。复用深塔头像识别/入口模板和现有角色战斗类。

**Tech Stack:** Python、本地.venv、ok-script、OpenCV、unittest。

**Spec:** `docs/superpowers/specs/2026-09-18-sea-ruins-design.md`

## Global Constraints

- 保留游戏预设成员和顺序，不替补；只选择无重复角色的上下半组合。
- 顺逆属性按周期/关卡/半场写在代码，过期停止。
- 简体中文、16:9；7—11层一次挑战；不包含无尽和领奖。
- 用户工作区已有修改不纳入本次提交。
- 中等功能版本更新1.79.00→1.80.00，验证后提交、注解标签、推送GitHub。
