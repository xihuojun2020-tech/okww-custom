## 2. 已定位的代码路径

主要文件：`src/task/CharacterTrialTask.py`。

| 方法 | 当前行为 | 局限 |
| --- | --- | --- |
| `_open()` | 在活动列表查找初露峥嵘；滚动点约为画面 (0.15, 0.50) | 这是活动入口滚动，与底部头像滚动不同，必须用调用栈区分 |
| `_view()` | 连续两次识别到头像位置、匹配稳定即返回 | 稳定的旧位置也可能在滚动动画开始前返回；未将结果与滚动动作关联 |
| `_scroll_view(before, direction)` | 移到中间头像，滚动一格，等 0.35 秒，取稳定视图，以重叠头像位移中位数计算 delta | 无匹配即退出；无法区分输入未响应、延迟动画和视觉匹配失败 |
| `_scan()` | 正反方向各试一次；位移均小于画面宽度 0.8% 即报“头像滚轮未生效，无法确认完整名单” | 两次零位移不足以证明滚轮不可用，缺少响应观察窗口与有限重试 |
| `_edge()` | 连续三次小位移后，结合截断标记确认边界 | 未响应也能形成连续零位移，必须结合此前已确认移动和页面有效性 |
| `_select()` | 寻找目标头像，未找到时继续滚动 | 应复用相同的滚动反馈，避免扫描和选择采用不同判定 |

`src/task/character_trial.py` 的 `detect_portraits()` 使用参考分辨率 2048×1152 的头像条几何，`unique_match()` 使用相似度和唯一性差值保护，`merge_view()` 要求唯一连续重叠。这些保护不能为消除报错而删除。

现有 `tests/TestCharacterTrial.py::TestTrialRecognition` 覆盖真实静态页面缩放；任务测试中的 `test_edge_cannot_accept_clipped_or_unmoving_list` 将 `_scroll_view` 模拟成零位移。它验证保护性报错，但不能证明真实滚轮输入有效，也不能覆盖动画延迟。

## 3. 候选原因与确认办法

| 候选原因 | 必需证据 | 对应处理 |
| --- | --- | --- |
| 输入没有落在游戏头像条或窗口未就绪 | 输入后头像条图像不变；记录后端、窗口状态、实际坐标；同一状态手动滚动比较 | 检查现有坐标转换和输入后端；仅修复已复现的路径 |
| 动画延迟被当成零位移 | 输入后先出现稳定旧位置，稍后相同头像产生一致位移 | 引入动作后的响应观察窗口，不以两张相同位置帧立即判失败 |
| 头像匹配/几何定位失败 | 前后画面肉眼移动，但匹配缺失、歧义或位移不一致 | 对照现场裁剪帧检查几何和匹配，不盲目降低阈值 |
| 当前位置确实是边界 | 有先前移动记录，到边缘后多次无移动，截断标记一致 | 确认边界并反向扫描，不能直接结束完整性验证 |
| 界面变化，列表无需滚动 | 真实页面能证明完整名单，左右均无截断，数量和布局有样本验证 | 另加静态完整布局分支；当前几何无法证明时继续拒绝，不猜名单 |

### 任务二：滚动后观察与有限重试

修改：`src/task/CharacterTrialTask.py` 的 `_scroll_view()`；必要时在 `src/task/character_trial.py` 提取纯位移计算函数。

- [ ] 保留 `_scroll_view(before, direction) -> (after, delta)` 对调用方的接口，避免修改战斗和领奖流程。
- [ ] 每次输入前确认任务未停止、当前确为试用页面、有有效头像与新画面；移动到已检测头像中心，经过短暂悬停再发送单格输入。
- [ ] 首轮设计参数：悬停 0.15 秒、响应观察最长 1.5 秒、采样间隔 0.1 秒、每方向最多 3 次输入。这些是待实机校准的初值，不是已经测得的最优值。
- [ ] 观察期内将最新视图始终与该次输入前视图比较；旧位置稳定不能立即结束等待。移动发生后再要求连续两次位置稳定。
- [ ] 用多个唯一匹配头像的位移一致性检查结果；没有匹配时不能返回 delta=0，应记录识别失败。保留匹配歧义保护。
- [ ] 未见运动时在同一安全区域有限重试，每次更新基准帧；单次步长仍为一格，确保相邻视图有重叠。
- [ ] 所有等待和重试检查 `_guard()`；停止立即传播，不重试或追加输入。

建议控制流：

```text
验证页面和基准视图
最多尝试3次:
    检查停止 → 定位头像中心 → 悬停 → 单格滚动
    在1.5秒窗口内采样:
        检查停止和页面
        匹配基准头像 → 检查位移一致性
        已移动且连续两次稳定 → 返回稳定视图和位移
    记录本次无响应；更新有效基准视图
返回最后视图和零位移，由扫描层判断边界或整体未响应
```
