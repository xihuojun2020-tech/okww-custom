# 账号总配置与完整性保护实施计划

依据：[账号总配置与完整性保护设计](../specs/2026-08-18-account-config-integrity-design.md)

目标发布：`1.06.00`

## 实施原则

- 所有测试只使用临时目录和夹具，不接触用户真实 `working/configs`。
- 先写失败测试，再实现对应行为。
- 主程序对 `account_master_config.json` 只有读取能力。
- 恢复工作副本和写入运行状态都使用原子替换。
- 差异未解决时，任务启动守卫必须在刷新游戏窗口或抢占前台之前返回失败。
- `TaskDisabledException` 继续向上传播，停止操作不能被完整性检查吞掉。

## 任务 1：纯数据完整性核心

文件：

- 新增 `src/config_integrity.py`
- 新增 `tests/TestConfigIntegrity.py`

实现：

1. 定义总配置、工作副本、运行状态和事件目录路径。
2. 定义 schema v1、稳定 `profile_id`、别名、任务配置、计划记录、序列和扩展字段验证。
3. 把总配置与旧 `daily_profiles.json` 投影成同一规范结构。
4. 生成结构化差异和 SHA-256 指纹。
5. 比较上次由用户接受的总配置指纹。
6. 使用差异指纹复用未处理事件目录，并保存快照、差异、清单和标记。
7. 实现进程内锁、临时文件、刷新、复读校验和 `os.replace` 原子写入。
8. 实现受保护字段恢复事务；不得覆盖运行状态。
9. 对总配置路径提供写入拒绝守卫。

测试：合法/缺失/损坏/过新 schema、别名冲突、序列悬空、格式差异、受保护差异、
指纹变化、事件去重、恢复成功、恢复失败、原子写入和总配置字节不变。

## 任务 2：启动和任务启动门禁

文件：

- 修改 `main.py`
- 修改 `custom_ok/ok/gui/MainWindow.py`
- 新增 `src/gui/ConfigIntegrityDialog.py`
- 扩展 `tests/TestConfigIntegrity.py`

实现：

1. 在构造 `OK` 和任务对象之前完成只读预检并把门禁对象放入应用配置。
2. 安装统一任务启动守卫；GUI、命令行计划任务和自动启动共用同一检查。
3. 主窗口首次显示时展示异常阻断对话框。
4. 支持“已知晓并查看差异”“确认总配置修改”“按总配置恢复”“退出手工处理”
   和“重新检查”。
5. 安全模式只允许查看、导出、打开目录、复检和退出。
6. 任务启动守卫在任何设备刷新、窗口激活或任务排队之前拒绝启动。

测试：启动一致、首次指纹确认、差异阻断、已知晓仍阻断、恢复后解锁、命令行启动阻断。

## 任务 3：只读账号配置 UI

文件：

- 修改 `custom_ok/ok/gui/tasks/LabelAndLabel.py`
- 修改 `src/task/DailyTask.py`
- 修改 `src/task/MultiAccountDailyTask.py`
- 更新相关 GUI 测试

实现：

1. 只读标签可靠显示布尔、数字、列表、字典和空值。
2. 每日任务账号专属字段改为只读展示；保留选择当前账号方案的下拉框。
3. 隐藏或禁用创建、重命名、删除、导入以及保存方案的入口。
4. 多账号序列内容只读展示；当前运行序列和起始账号仍作为运行选择存在。
5. 所有受保护 UI 值来自已验证的总配置快照。

测试：控件不写配置、列表显示正确、选择方案只改变运行选择、管理入口不可调用。

## 任务 4：每日任务配置和运行状态拆分

文件：

- 修改 `src/task/DailyTask.py`
- 扩展 `src/config_integrity.py`
- 新增或更新每日任务测试

实现：

1. `load_daily_profiles()` 返回总配置快照的兼容投影。
2. 删除初始化补全、迁移写回、切换旧方案保存和逐字段持久化。
3. 任务执行通过只读方案访问器读取账号专属字段，不从残留 `DailyTask.json` 读取。
4. `switch_profile()` 只切换运行选择并验证目标，不保存旧方案。
5. 完成记录按显式 `profile_id` 写入 `account_runtime_state.json`。
6. `get_last_completed()` 从运行状态读取。
7. 临时退登开关使用内存覆盖，不写持久配置。

测试：A/B 方案切换不改任何方案文件、崩溃前后账号配置不混合、完成记录写入明确账号、
运行状态损坏进入门禁且不自动清空。

## 任务 6：退出流程已知缺陷同步修复

文件：

- 修改 `src/task/MultiAccountDailyTask.py`
- 修改 `tests/TestMultiAccountDailyTask.py`

实现：

测试：终端菜单无确认框误报、状态推进重置次数、实际输入次数准确、停止立即生效。
