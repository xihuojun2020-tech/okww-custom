- [ ] 首先读取新帧：已在总览则直接成功；仍是结算页则定位精确的返回深塔按钮；未知页仅等待。
- [ ] 使用按钮局部区域 x=0.20..0.50、y=0.78..0.93，实际比例以两张2560×1440原图校准；避免匹配右侧再次挑战。
- [ ] 确认任务未停止、游戏窗口与画面有效后点击；每次点击后获取新帧，不复用旧 OCR 框。

- [ ] 总览通过同一新帧中的三塔标题组合及页面锚点确认，必要时两帧稳定检查；不要三个标题各等待8秒累加。
