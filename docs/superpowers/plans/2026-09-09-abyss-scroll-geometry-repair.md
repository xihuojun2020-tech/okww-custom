# 深塔滚动定位与编队复核修改计划

**Goal:** 修复滚动后体力裁剪错位及角色槽位失效，确保先可靠识别仓库，再安全清理和建立队伍。

**Architecture:** 每个稳定画面重新定位实际卡片行；所有头像、体力、等级、选中标记和点击共用同一套卡片几何。屏幕记录用于导航，角色身份用于最终定位，滚轮移动量不再代表页码。

**Tech Stack:** Python 3.12、现有 OpenCV / NumPy / OCR、unittest / pytest，不增加识别模型或依赖。

**Spec:** 本次用户要求与 NAS 运行 `20260909-200505-3498bad879ca`；属性与共享体力约束沿用 `2026-09-07-abyss-element-planning.md`。
