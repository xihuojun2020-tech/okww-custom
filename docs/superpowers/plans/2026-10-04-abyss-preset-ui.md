# 深塔新版预设编队实施计划

**目标：** 在新版深塔编队页选择真实预设，按当前周期属性及疲劳值分配队伍，沿用已有地图战斗和结算流程。

**方案：** 保留现有入口、选层、战斗和结算逻辑；以角色列表／预设编队页替代旧快速编队入口。扫描真实预设的成员和疲劳值，仅把完整且可确认的预设交给全局分配器。选择后复核三人顺序和下方阵容，再开启挑战。

**范围：** `src/task/AutoAbyssTask.py` 负责页面交互；`src/task/abyss_allocation.py` 负责赛季规则及真实候选队伍分配；相关测试验证截图几何、规则、分配和续关。版本、说明、更新包与 GitHub／NAS 同步按仓库规则执行。

1. 以所附新版编队截图建立离线识别测试，覆盖角色列表、预设页、已选队伍和未知页面。
2. 为新版预设页实现有界滚动扫描，识别序号、三名成员及箭头左侧的当前疲劳值；右侧为完成本关后的预计值，不能当作当前账本。未知数据不参与候选。
3. 分配器接收真实预设候选，禁止合成替补队与自由队；同步四组属性规则。
4. 点击预设后核对选中标记、成员顺序和下方阵容；失败截图停止。沿用“开启挑战”后的原流程。
5. 回归四层入口、结算续关、失败返回，更新文档、版本，校验并发布。
