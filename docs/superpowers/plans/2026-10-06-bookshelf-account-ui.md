# 书架风格账号界面优化方案

**目标：** 将资源库漫画／文档书架的视觉语言用于账号界面，同时保留已有任务、序列、状态与草稿行为。

**架构：** 继续使用 PySide6 与 QFluentWidgets，样式由现有 `CodexTheme` 统一定义。顶部账号选择保留；下方左侧分类、右侧总览或设置，复用现有组件和数据仓库。

**技术栈：** PySide6、QFluentWidgets、QSS；本方案不增加网页嵌入层和在线字体依赖。

**执行范围：** 本次已实施图一的高度错误修复，版本 1.97.14。下述书架风格为待确认的设计方案，示意图不是已经安装的界面。后续按任务逐项实施和验收。

**预览：** [任务总览](../../images/bookshelf-account-overview-proposal.png) · [账号执行顺序](../../images/bookshelf-account-order-proposal.png)。

## 1. 参考来源与取舍

已检查资源库项目 `E:/AI work/抖音下载` 中的真实源码：

| 来源 | 可借鉴内容 |

| `independent_apps/document_reader/frontend/src/style.css` | 与漫画书架统一的导航选中态、面板与工具栏 |

结合技能：

- **UI UX Pro Max：** 采用可见键盘焦点、文字对比度、固定导航不遮挡内容、4/8px 间距及一致控件状态原则。
- **Frontend Design：** 从用户指定参考提取具体颜色和尺寸，把同类操作做成同类组件，文案直接说明操作结果。
- **Writing Plans：** 按主题、导航、任务总览、设置及验收分步落地。
- 技能数据库的两次设计系统检索偏向营销展示页／其他产品配色，与本项目不符，未作为本方案依据。Qt 未列入该技能的栈目录，因此不套用 Web 布局代码。

书架的封面网格用于找书；本项目需要连续查看执行状态，所以任务采用横向行。参考的是色彩、导航、层级、圆角和操作反馈。

## 2. 总体布局

```text
现有主窗口导航与标题
┌─────────────────────────────────────────────────────┐
│ 账号 [ A4 · 示例账号                  ▾ ] 新建账号 更多 │
├────────────┬────────────────────────────────────────┤
│ 任务总览    │ 任务总览                      最近核验时间 │
│ 账号序列    │ 序列一 · A4     归属设置                  │
│ 账号执行顺序 │ 全部 / 待完成 / 需处理 / 已完成            │
│ ────────── │                                        │
│ 账号识别信息 │ 本日任务                                │
│ 待办提醒    │ 聚落 / 首领材料 / 凝素 / 无音区 / 活跃度    │
│ 日常与声骸 ▾ │ 周常与独立任务                          │
│ 周常安排  ▾ │ 周本 / 深塔                              │
│ 深塔        │ 手动提醒                                │
│ 海墟与活动 ▾ │ 海墟 / 活动                              │
│ 其他设置    │                                        │
└────────────┴────────────────────────────────────────┘
```

- 上方账号选择及新建／更多操作的位置保留；序列和槽位在总览摘要展示，可跳到归属设置。
- 账号模块内侧栏目标宽度 208px；右侧获得全部剩余空间，只有右侧内容滚动。现有主窗口的导航结构沿用。
- 左侧优先呈现“任务总览、账号序列、账号执行顺序”，其余设置按现有分类组织。
- 分组标题仅用于分类；有子项的分类具有明确展开箭头，当前具体页面用浅蓝圆角选中态。
- 右侧标题、筛选、正文依次排列，禁止通过拉伸标题或说明填满窗口。

| 面板圆角 | 12px | 设置分区、任务组 |

| 页面内边距 | 20～24px | 窄窗口降为 12～16px |
| 分区间距／面板内距 | 16px／16px | 形成层级 |
| 标签与说明间距 | 4px | 紧凑关联 |
| 基本文字 | 14px | 与现有 Qt 内容密度兼容 |
| 标题／分区／说明 | 20px／15px／12px | 简洁层级 |

字体使用系统已有的微软雅黑，回退到可用中文系统字体；账号槽位和时间优先等宽数字。图标统一使用当前 FluentIcon，不混用 emoji。

信息状态继续显示文字，并建议采用：运行中蓝、待完成深灰、等待中灰、需要处理红、已完成绿。较浅的底色仅作辅助，所有正常正文对比度验收至少 4.5:1。

本方案统一现有浅色产品；当前主题明确没有深色分支，不在本次引入不完整的深色主题。

## 4. 任务总览

### 4.1 页面上方

标题下显示“序列一 · A4”与“归属设置”；右侧显示最近**成功核验**时间。不能把界面刷新时间写成游戏核验时间。

筛选使用小型圆角按钮：“全部、待完成、需要处理、已完成”，各自显示数量。缺省显示全部所选任务，空分组隐藏，已完成组缺省收起。

### 4.2 任务行

每行固定信息顺序：

```text
任务名称                         状态标签     设置／操作
周期 · 进度 · 证据状态            最近完成／尝试时间    ▾
```

- 简单任务约 64～72px，长名称或更多信息自动增长，不能裁掉文字。
- 普通行只显示名称、状态、进度和时间，展开后查看完整来源、完成记录及失败原因。
- 自动任务保留“设置”；可复核的任务显示“复核”。人工提醒显示“标记完成”，完成后可“撤销完成”。
- 深塔显示“单独启动”，不能通过总览点击变成多账号每日任务的一环。
- 读取失败保留带提示的同账号快照；停止标记写入，切换账号立即清除旧快照。
- 定时刷新复用行控件，不使焦点、详情展开或滚动位置跳动。

### 4.3 时间与状态

- 每日任务北京时间 04:00 换日；每周任务周一 04:00 换周。
- 时间到只重算状态，仍由用户手动启动现有任务。
- 周本保留周一执行、周日复检及每周三次限制；其他日期不因总览刷新调用。
- 日常完成依据真实检查／领奖记录。没勾选聚落不打，也不能据此断言活跃度不足。
- 活跃度宝箱仍在全部所需耗体力任务结束后领取；最终实际读取不到 100 则报错。
- 材料数量是剩余需求，旧刷法、目标累计和达标后的转移规则沿用现有实现。
- 深塔按游戏识别出的赛期记录；用户此前的“六天十一小时”属于当时信息，不硬编码为当前倒计时。
- 海墟／活动维持手动标记，可设每日、每周、自定义重置或不自动重置，不执行。

## 5. 账号序列与执行顺序

### 5.1 账号序列（可编辑）

- “序列一 A”与“序列二 B”使用横向选择按钮，替代当前紧邻的列表式选择。
- 下方固定槽位表：槽位、账号、参与执行、任务摘要。
- 列表严格 A1～A10 或 B1～B10 数值顺序；空槽位显示“空槽位 · 跳过”。
- 只有有归属的账号允许勾选参与；切换序列沿用保存状态。
- 暂保留现有选择变更即保存逻辑，显示“正在保存／已保存／保存失败”，避免做成可编辑草稿却暗中立即保存。
- 旧用户自定义序列仍保留可访问入口，固定序列之外的编辑行为不能被视觉改造删除。

### 5.2 账号执行顺序（只读）

- 使用同一表格外观，但没有勾选框和拖拽手柄。
- 上方显示有效账号链，例如“A3 → A4”；未参与及空槽位在完整槽位详情中查看。
- 正在运行时显示冻结快照与当前／下一账号，改动新配置不改变本次执行快照。
- “固定槽位”收起后只显示标题、参与数和箭头，高度由内容决定。
- 将当前没有操作意义的“等待操作”调整为说明性状态；发生保存／读取错误时就地显示具体原因。

## 6. 设置页与全局统一

- 同类设置放在白色圆角面板；面板内使用同一标签、输入框和说明位置。
- 普通配置缺省可见，较少使用的高级项收起，标题摘要保留当前重要值。
- 保存／放弃草稿保持现有行为，靠近账号操作区显示草稿状态；切换分类与账号不丢草稿。
- 不在每个字段外再套一层大卡片；分区边框和行分隔线各承担一个层级。
- 五个主页面共用颜色、按钮、DisclosureHeader、SectionPanel 与 FlatSettingRow；任务页和工具页不保留另一套突出的旧蓝色或背景。
- 错误提示在问题所在区域显示，并提供可用的修复入口；提示不会反复弹窗抢焦点。

## 7. 自适应与交互验收

- 物理窗口 1280×800、1440×900、1920×1080，各测试 100%、125%、150% 缩放。
- 可用内容宽度较小时，侧栏可降至 180px；右侧筛选自动换行，操作移到第二行，设置标签与控件上下排列。
- 大窗口内容仍从顶部排列，不扩大任务行填满屏幕。
- 正文无横向滚动；长账号别名允许缩略并用提示显示完整值，核心状态、错误和时间可以换行。
- Tab 顺序符合视觉顺序；每个按钮有可见焦点，图标按钮具有中文可访问名称。
- 展开和收起不改变账号选择、不调用任务、不清空记录。
- 不增加页面进入动画；状态变化不闪烁，不引入循环动效。
