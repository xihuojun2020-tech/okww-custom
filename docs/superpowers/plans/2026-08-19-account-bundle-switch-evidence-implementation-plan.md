# 账号配置包、序列恢复与切换证据实施计划

依据：[账号配置包、序列恢复与切换证据设计](../specs/2026-08-19-account-bundle-switch-evidence-design.md)

目标发布：`1.08.00`

## 实施原则

- 所有迁移、导入、恢复和清理测试只使用临时目录，不写用户真实运行配置。
- 先补失败测试，再实现相应行为。
- 总配置仍是唯一权威；UI、任务配置保存和兼容副本不得反向写入它。
- 任何受控写总配置操作都必须显式确认、事务执行、完整复检和字节级回滚。
- 正式任务与测试任务必须使用同一账号切换入口。
- 失败证据模块不得发送输入、抢占窗口或吞掉 `TaskDisabledException`。
- Python 命令使用项目 `.venv`。

## 任务 1：序列双源迁移与遗漏恢复

文件：

- 修改 `src/config_integrity.py`
- 扩展 `tests/TestConfigIntegrity.py`

实施：

1. 解析工作副本顶层 `sequences` 和旧 `MultiAccountDailyTask.json` 的明确序列字段。
2. 规范序列名，通过 UUID、完整名称、精确短名、备用名和掩码身份映射成员。
3. 实现单源采用、双源一致、双源冲突阻断，并保留空序列及成员顺序。
4. 首次锚定使用统一双源解析。
5. 为“合法总配置序列为空、旧任务序列非空”提供检测和显式恢复事务。
6. 恢复事务更新总配置、工作投影和 accepted fingerprint，失败三文件字节回滚。
7. 写入一次性恢复标记；拒绝时零写入，总配置非空时禁止覆盖。

## 任务 2：账号配置包 v2 核心

文件：

- 新增 `src/account_config_bundle.py`
- 新增 `tests/TestAccountConfigBundle.py`

实施：

1. 定义 `manifest/master_config/runtime_data/preferences/extensions` 结构和分区 SHA-256。
2. 从已验证总配置快照导出，运行数据按稳定 UUID 分区。
3. 实现纯内存预检、版本/结构/身份/引用验证和增删改摘要。
4. 标记导出后外部修改；只有结构验证通过并再次明确信任才允许继续。
5. 将旧 v1 导出升级为 v2 候选并复用序列迁移规则。
6. 实现完整替换事务、工作投影重建、运行记录恢复、复检和回滚。

5. 主窗口启动调用新备份引擎，不再用散文件复制和单日期标记。
