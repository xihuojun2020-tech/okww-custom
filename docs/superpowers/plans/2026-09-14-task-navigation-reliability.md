> 执行说明：用户已批准实施；1.71.00 首批代码和自动测试完成，实机验收及后续批次尚未完成。详见 [首批覆盖报告](../../reviews/2026-09-14-navigation-rollout-1.71.00.md)。实施时按下列批次逐项执行；使用仓库可用工具，不依赖未安装的子代理技能。并行工作仅在用户授权且文件责任不重叠时安排。

**Goal:** 为适用任务建立可验证的页面转换及目标状态恢复，降低丢点击导致的失败，同时杜绝重复消费和错误账号/关卡操作。

**Tech Stack:** 仓库 .venv Python、ok-script、现有 OCR/模板、Qt 工具页、现有诊断与 NAS 上传服务，不新增输入后端或并发点击线程。

**Spec:** [详细设计与35文件清单](../../references/task-navigation-reliability.md)，基线 3b75ddf1 / 1.70.07；[源码定位附录](../../reviews/2026-09-14-task-navigation-inventory.md)。

## 预计工作量与决策点

建议按 A→B→C/D→E→F→G 的依赖推进。G 的诊断接口随 A 设计，最终 UI 和覆盖收口可后置；C 与 D 只有在不修改同一公共 helper 时才可并行。完整推广是多个版本的工作，不宜一次大版本全开。
