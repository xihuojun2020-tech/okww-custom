## 本版行为

1. `BaseWWTask.navigate_ui` 提供显式选择接入的导航流程。每次新截图先校验任务、账号输入 guard 和窗口，再识别来源/目标；连续三个不同捕获时间戳的来源观测、按钮中心漂移不超过画面比例 0.005 才输入。输入后至少观察三秒，最多三次输入尝试；默认总预算十八秒，嵌套导航继承较早截止时间。
2. 目标已经出现即结束；来源和目标同时命中属于歧义，等待而不输入。未知页面只等待，超时停止。首次识别的目标身份和分辨率锁定，改变后不重新累计稳定帧去点击新对象。按钮位置按实际游戏帧宽高归一化。
3. 若梦的前往、单人挑战、快速编队使用公共层；完成编队由一次固定坐标点击改为识别“详情＋完成”页后点击当前完成按钮，返回页必须与原关卡一致。不自动启动挑战，不将编队准备记为活动通关或领奖。
4. 共用指南入口只在大世界队伍 HUD 仍存在时尝试打开。先使用已配置指南热键，未生效后使用原 Alt 图标入口，按键释放由 finally 保证。已确认指南页后，页签选择保留原单次输入；没有凭灰色页签猜测“该页签已经选中”。
5. 聚落调用公共指南预算，不再在外面重跑三轮“恢复世界＋开书”。完成检查的每日任务页必须识别到原有 `数字/180` 进度内容才返回成功；识别失败则该页不能作为已成功打开页面的截图留档。
6. 工具→日志与诊断卡片新增最近五个导航操作。本进程最多保留三十条摘要，界面可见时每秒读取本地内存，不访问 NAS。显示来源状态、输入尝试次数/实际上限、耗时、剩余预算、失败类别，使用现有 SectionPanel/QLabel 风格。

## 边界与保护

- 导航“成功”仅表示对应目标页被识别，不等于挑战通过、奖励领取、费用到账或截图上传成功。
- 未修改低层 click/send_key；没有给任何 run 加重试装饰器。自动战斗技能、拾取、弹琴、第二索拉与鼠标复位不插入稳定等待。
- 备用体力策略、pending_conversion、材料领取事务、周本费用单次确认、深塔选中/取消保护不变。
- 目前新接入均为同步任务。纯状态机 `Transition.tick` 不阻塞，但尚未接入后台 run；不能把同步 `navigate_ui` 直接放进 FastTravel/AutoLogin/SkipDialog。
- 十八秒是导航自身预算，不包含导航外的 ensure_main/wait_book。截图与 OCR 的原生调用也有自己的超时，不能承诺在绝对十八秒内中断一个阻塞的后端调用。
- 来源谓词必须代表特定页面，目标谓词必须代表特定终态；跨关卡应提供身份并沿用任务专用验证。公共层不会凭按钮同名证明关卡一致。
- 日常页新判据需要使用端确认当前语言/活动版本仍显示 `/180`；识别不到时停止留档，不能回退成“点击过就算打开”。其他完成检查页尚未改造。
