# 账号任务总览与深塔周期发布验证（1.97.12）

## 范围和实施

基于 1.97.11，按用户批准的 ALAS 式账号界面方案实施，并完成先前批准的深塔账号周期与失败续跑改动。1.97.11 已实现的每日优先级、材料剩余目标、最终实际活跃度复核继续沿用。

- 顶部账号选择与草稿操作保留。下方左侧分类，右侧切换任务总览和设置；账号序列也进入分类设置。
- 总览分运行中、待执行／待办、等待中、需要处理、已完成，显示最近开始、完成与下次刷新／检查时间。读取正式账号选择，刷新不重建编辑控件、不覆盖未保存草稿。
- 日常执行与多账号断点统一按北京时间 04:00 游戏日；周常按周一 04:00 游戏周。周本分别展示周一执行、周日复检。刷新只改变状态，不启动任务，也不清空历史或累计材料。
- 聚落使用所选列表摘要检查点；活跃度使用实测积分与领取记录；材料使用既有 confirmed/pending 账本，不重复计数。收尾失败单独显示，不取消已经核验的活跃度完成。
- 海墟、矩阵、初露峥嵘和活动仅人工提醒，支持完成、撤销及每日／每周／自定义一次／不重置四种规则，不参与每日自动执行。
- 深塔单独启动，开始和结束通过游戏特征码核验账号。按实际倒计时区间匹配赛期，逐关保存通关与失败队伍。失败后排除该队并重新规划，候选耗尽后处理其他塔；识别不完整记录待核验。提供人工重新评估入口，保留通关和失败历史。

## 发现和修复

原多账号自然日断点与 04:00 游戏日不一致，已换用独立游戏日命名空间，避免误用旧自然日完成集合。旧历史时间统一按 UTC+8 解析，不把未来时间算作完成。

实机启动后发现外层账号页仍将序列编辑器固定放在总览下方，导致总览和导航被压缩。已将序列管理放入左侧分类，外层页面只保留完整账号编辑区；新增真实外层页面高度与切换检查，避免只验证内部子页面。

补充状态保存／配置读取失败仅记录诊断，不掩盖原始任务结果。账号切换后丢弃旧异步返回，运行状态使用 profile_id、task_id、run_id 归属，避免串号。
