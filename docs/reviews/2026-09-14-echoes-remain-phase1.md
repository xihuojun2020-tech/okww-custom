# 1.69.00 若梦仍有回声第一阶段执行记录

## 已实现的边界

新增 `EchoesRemainTask`，位于活动页的限时活动分类，显示共享名称「若梦仍有回声」。执行 F1 活动入口、前往当前关卡、单人挑战、快速编队、替换试用三人、最终截图复核、完成返回。返回编队页即停止，不发送开启挑战，不进行战斗、结算、积分判断或领奖。

共享活动身份为 `echoes_remain`。本任务不写入完成检查业务状态，`activity_complete` 始终为 false；`formation_ready` 仅表示编队阶段成功。

## 导航与身份核验

沿用角色试用的局部活动列表 OCR 和有界滚动模式，点击后检查右侧活动标题及“前往”，没有固定活动列表行号。当前关卡读取右上角关卡名和浅梦/深梦。已位于明确的本活动关卡页时可继续；任意来源的裸快速编队页不作为可信活动上下文，重新从活动入口进入。

任务开始和结束复用 FeatureRun 特征码账号核验，中间输入检查任务与窗口上下文。没有使用 FeatureRun 的角色试用完成保存接口，避免把本活动结果写进初露峥嵘。用户需要保持当前游戏账号的特征码绑定正确。

支持中文 16:9；页面等待通常最多 8 秒，活动入口点击最多 3 次，左右滚动各最多 16 步并检测无变化。超时停止，不无界重试。

## 试用编队与识别

`echoes_remain.py` 复用深塔卡片布局、金色选中边框及滚动条顶部检查；编号和时钟模板来自用户真实截图，存于 `assets/images/activities/echoes_remain`。没有新增全角色匹配或遍历仓库。

初态要求前三人编号为 1/2/3 且有金边、第 4～6 位有时钟且未选中，其他可见卡片无矛盾选中金边。第一排第七位也参与排除检查，下方可见两排进行轻量选中边框检查。

初态确认后按第一排第 1～6 位依次点击，坐标为 `x = .131 + .1221 * 列索引`，`y = .24`，索引从 0 起。每次留 0.3 秒响应间隔，期间不逐点击 OCR 或保存截图。

结束请求新帧，核对前三人已取消、第 4～6 人编号 1/2/3、金边和试用时钟。刷新后仍不符时，仅 `(0,0,0,1,2,0,0)` 允许补点第六位一次；其他差异停止。已精确达到最终状态时不会重复切换选中状态。

真实 OCR 测试发现 720p 左上人物图标会被读成“三详情”，已收窄标题 ROI 排除人物图标，仍严格匹配“详情”。没有放宽全局 OCR 或匹配阈值。

## 证据与性能

初始和最终各用新帧，多个检测器共享同一帧；只处理标题、按钮、卡片编号、时钟及选中边框等局部区域。整帧可能仍由既有捕获后端提供，没有宣称局部识别等于局部底层捕获。

最终复核通过后同步保存截图至当前安装存储映射下 `screenshots/echoes_remain/formation_<唯一编号>.png`，配套同名 JSON 记录账号内部身份、关卡、阶段、捕获时间和检查结果。屏蔽顶部性能栏与底部身份码。调用已有截图保存钩子，资料可进入手动诊断 ZIP，遵循诊断保留规则。

截图落盘成功后才点击完成；返回编队且结束账号核验通过后更新 JSON 为 formation_ready。若只存在 formation_verified，不能声称已成功返回编队页。初始状态图暂存内存，换人复核失败时另存初态与故障截图。

## 验证方式和结果

最终主回归 184 项通过（3 条依赖警告，11.19 秒），角色试用图像组独立进程 8 项通过（2 条依赖警告，3.69 秒），合计 192 项。日志分别为 test_out/echoes-final-regression.log 和 test_out/echoes-trial-isolated.log。

- 用户快速编队初始截图：720p、1080p、1440p、2160p 下前三人金边和编号、三个时钟全部通过。
- 第二组三个不同试用角色的真实截图：相同四种分辨率的时钟检测通过，普通角色负样本不被认作试用。
- 最终选中状态为合成 UI 变更样本，四种分辨率通过；不把合成图称为真实点击后的截图。
- 五个真实页面（活动、两个不同关卡、编队、快速编队）在四种分辨率完成局部 OCR、按钮区分和错误页面排除。
- 流程测试覆盖六次点击、最终态幂等、初态异常零点击、最后一名漏选修正、错序停止、用户中断、当前关卡导航、同步脱敏截图保存以及完成后不启动挑战。
- 与深塔、角色试用逻辑、任务分类、账号核验和第二索拉做回归。图像测试框架持有全局执行器，多个图像测试类同进程运行会触发旧执行器 FinishedException；角色试用图像组另起进程验证，不修改生产代码规避问题。

没有运行真实游戏。本阶段实际点击响应、输入延迟、其他账号布局及当前活动页面变化由用户手动验收。未提供锁定当前关卡的专用样本，若不能进入编队，将按页面超时报告，不猜测已完成。

## 用户验收

1. 更新到 1.69.00 并重启，在当前账号已登录、特征码绑定正确的情况下运行「若梦仍有回声」。
2. 确认自动进入当前关卡快速编队，先取消前三人，再按位置选入三个时钟角色。
3. 确认最后返回三人编队页并停止，没有开启挑战。
4. 检查本地截图及 JSON；失败时手动打包上传诊断。不要把当前编队成功视为浅梦或深梦通关。

下一阶段仍是用户已确认的各难度通关一次、浅梦后自动深梦、深梦后自动下一大关；具体战斗、支援声骸和结算流程尚未接入。
