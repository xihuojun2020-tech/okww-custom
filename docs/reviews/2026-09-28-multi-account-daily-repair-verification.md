# 1.87.03 多账号每日任务修复验证

## 依据与范围

- 故障诊断：`docs/reviews/2026-09-28-multi-account-daily-diagnostics.md`。
- 实施方案：`docs/superpowers/plans/2026-09-28-multi-account-daily-repair.md`。
- 本报告验证的是本地代码与离线图像；NAS 上使用端今日账号并未被本机远程控制，完成状态需在更新后实机补跑核实。

## 变更

1. 角色强制复核采用高分立即确认、稳定中分三张独立帧确认；异角色分差不足仍拒绝。换号/窗口上下文变化时清空旧身份；同一角色成功复核后清除 `_identity_unconfirmed`，避免已确认角色仍被循环拒绝。
2. 周本活动页按 OCR 所在行读取“本周剩余可收取次数”；新增双倍奖励行不再遮蔽计数；`0/3` 被视为合法读数。
3. 通用领奖路径扩大画面底部图标搜索区，并以一秒短段重新识别目标。连续无进展后最多六次短步调整；确认领奖文字后才返回。超时保存截图，并在所有退出路径释放方向键和跑步输入。TacetTask 仍在原有领奖弹窗和体力结算路径做成功确认。

## 实机验收边界

- 需在使用端安装 1.87.03 后补跑 B8、两个日志中脱敏的失败账号，以及 B10 周本补检。
- 验证成功须看到队伍身份确认、真实战斗动作、领取弹窗和体力变化、活跃度完成、周本剩余次数变化或已为零，以及多账号完成记录。
- 无法从日志脱敏值反推具体 B 编号。未复跑前不能宣称上述账号已经完成。
- 中分确认下限 .82 与分差 .08 已由两组故障正样本和当前负向行为测试约束；其他角色/画质可能需要额外真实样本校准。若出现误识别，应保留现场并追加相似角色图片，不应直接扩大接受范围。
