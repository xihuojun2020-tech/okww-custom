## 5. 如何根据证据判断错误位置

| 观察结果 | 优先定位 | 仍需避免的推断 |
| --- | --- | --- |
| 视频队伍UI清楚，程序帧也同样清楚，但in_team失败 | BaseWWTask.in_team、模板/缩放/阈值 | 未拿到实际匹配帧前不能直接降阈值 |
| 视频正常，程序帧停住、滞后或内容不同 | WGC/其他采集后端、TaskExecutor帧更新、HWND | 录像流畅不证明程序截图流畅 |
| 实际画面短暂隐藏队伍UI后恢复 | 切人局部等待、动画状态处理 | 不直接扩大所有任务等待时间 |
| 画面已出现奖励/结算，程序仍寻宝 | DomainTask阶段判断及奖励门禁 | 无图标不一定等于无奖励 |
| 画面仍有敌人，combat_once却返回 | 异常语义、战斗状态复核 | _in_combat=False不是胜利证明 |
| 复活/死亡弹窗出现 | 复活识别与死亡恢复路径 | 不归为普通队伍识别闪烁 |
| 输入投递失败，或发往错误窗口 | 输入接口/窗口绑定 | 不仅凭按键日志认定已执行 |
| 备用允许且充足，领取/补充流程正常 | 继续挑战符合策略 | 不认定current<40就是bug |
| 未成功领取但used已递增 | use_stamina结算确认与记账 | 推算值不等于实际余额 |

每项结论必须引用run_id、日志文件行号、视频时间和frame_id；缺一类证据则降低置信度。区分直接证据、代码推演和猜测。
