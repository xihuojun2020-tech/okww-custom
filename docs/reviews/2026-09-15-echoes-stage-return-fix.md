# 若梦仍有回声：通关退出后停止修复

版本：1.75.03。

## 检查证据与原因

本机打包版日志显示 12:44:06 成功结算，12:44:16 退出副本到达活动页，12:44:33 报“活动结束账号核验未通过”。运行摘要确认本轮通关为溺梦魔影·深梦，outcome=success，仅完成一轮。

失败截图 `12-44-33.785_echoes_remain_failed_original.png` 显示活动页面，浅梦最高分数为 0；页面不显示账号特征码。代码把任何“最高分数”都视为已通关，提前进入完成审查并结束循环；随后在活动页直接读取特征码，触发无法读取的错误。截图中的关卡位置是完成审查滚动后的状态，不能据此推断退出瞬间自动选中的关卡名。

## 修复

读取最高分数数值：0 为待挑战，正数保留既有已通关判断；分数缺失则明确停止，不能默认为已完成。继续保留相同关卡防重放、失败退出停止与未解锁判断。

正常结束本轮后，通过已有 ensure_main 返回大世界，再执行原有严格特征码核验。不放宽账号绑定、开始/结束一致性或任务上下文保护。
