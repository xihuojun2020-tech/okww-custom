# 若梦金色面具声骸统一优先

## 范围与实现

用户提供金色面具图片，经比对为现有模板 `support/5.png`（第六项），并确认“所有角色优先选择它；不可选再按原类别回退”。

基于 1.79.05，在 `choose_support` 中给 index 5 添加统一最高优先级，随后按原类别顺序查找，其余顺序不变；去除重复的 index 5 检查。复用原解锁及图案可用性检测、连续两次选择确认、声骸实际类型与选中边框确认、装配后加号/占用判断。没有修改角色类别、战斗策略或增加配置。

版本与更新日志同步为 1.79.06，分支 `codex/echoes-mask-priority`。原工作区无关修改保持不变。

## 验证

先更新测试，旧实现出现 5 个优先级预期失败；修复后验证三类角色均优先 index 5，面具不可用时逐项回退到各自原优先级，无可用选项返回 None。已有真实选择页四种分辨率回放与闪烁页面等待用例同步为优先金色面具。
