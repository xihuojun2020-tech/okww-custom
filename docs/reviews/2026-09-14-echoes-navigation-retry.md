# 1.70.06 若梦仍有回声导航修复

## 问题与证据

本机 1.70.05 在 16:49:33、16:49:52 两次报“未进入活动编队页”。A3 特征码核验通过，故障截图仍处于溺梦魔影·浅梦关卡页，右下单人挑战按钮可见。固定坐标位于按钮内，现有证据不能区分动画期间过早点击和偶发输入丢失。

上一轮只修复快速编队的单次点击，前往和单人挑战仍只有一次输入。本次补齐整个导航路径，不改变活动的编队后停止范围。

## 实现

将已有快速编队重试提取为 _click_transition，三个入口复用。每次点击前等待连续三帧识别同一按钮、中心偏移不超过画面尺寸的 0.5%，帧间隔 0.35 秒；位置由最新 OCR 中心除以帧宽高归一化。每轮稳定等待上限 4 秒，点击后切页等待上限 3 秒，总共最多点击三次。

前往仅在本活动详情标题和按钮都识别到时点击，成功页必须具备活动标题、关卡名和单人挑战按钮。单人挑战每次重试前核对已选关卡名；编队页除了快速编队按钮，还必须识别左上方相同关卡标题。关卡不同立即停止；标题无法识别不能判定成功或继续盲点。已到目标页面不重复点击，用户停止和账号核验异常向外传播。

保留原快速编队诊断方式。前往截图前缀 echoes_event_enter，单人挑战为 echoes_single，快速编队仍为 echoes_quick。记录时间、归一化坐标、耗时和结果；顶部/底部各 2.5% 遮挡后交给现有截图接口。截图失败记录告警，不假称已经保存成功。
