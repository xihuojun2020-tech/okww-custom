## 已实施

1. **体力识别**：领域与无音区统一调用有效读数入口；最多三次新帧、资源栏局部 OCR。实际 0 正常返回，未知值持续存在则只保存一次失败证据并抛错。暂停、终止和失去画面直接传播。备用体力授权仍执行原规则。
2. **入口识别**：指南目标、聚落和材料规划删除以 `team_close` 推断编队的逻辑。识别“单人挑战”入口或真正的挑战开始按钮；进入编队沿用稳定导航预算。旧模板不足时使用右下区域“开启挑战/开始挑战”文字，含繁体及英文；提交开始挑战一次。
3. **可达性**：右侧详情局部识别不可传送提示，错误包含目标名称，保留原账号设置。移除标记不属于可用传送。无音区落在可传送地图时复用传送流程，抵达后寻找交互入口；不自行选择另一无音区。
4. **退出领域**：先无输入等待 15 秒，要求队伍及世界图标证据稳定，并排除领域。仍明确在领域才尝试退出；然后在原超时预算内等待世界证据。未知状态不连续 ESC，失败保留 `domain_exit_unknown`。
5. **补跑范围**：复用已验证账号 ID 下的完成记录，增加梦魇模式及目标列表的摘要键。仅本版完整成功才写入，历史笼统的完成记录不用于跳过。按当地时间 04:00 划分日刷新周期，跨日、换配置、获取声骸模式与全清模式互不冒用。声骸模式未确认获取时显式失败。
6. **日志区分**：体力未知记录重读次数与最终原因；地图不可达显示目标；补跑明确写出跳过已成功梦魇，但重新检查体力和活跃度。保留原子任务失败与账号失败记录，未把所有战斗恢复提示降级或隐藏。

## 有意保留的检查

体力会自然恢复，任务中也可能新增奖励，因此不凭历史“清体力完成”直接跳过。邮件、战令、最终活跃度继续复查；周本与每周任务沿用各自完成记录。梦魇检查点为完整子任务粒度，单个聚落的实时完成数仍由现有游戏页面读取，不把战斗函数一次返回当成全清。

本次未修改正式账号选择、别名验证、退登和登录路径，也未更改连续切号测试顺序。工作区其他文档删除与历史报告修改不纳入本次提交。
