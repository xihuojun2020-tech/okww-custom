# 1.97.14 账号序列收起高度修复验收

## 范围

处理用户图一中账号执行顺序页的大面积间隔与折叠标题过高问题；同时检查资源库漫画／文档书架源码，提供后续统一视觉方案。本次代码发布只包含布局修复，没有实施全部新视觉方案。

## 复现与原因

- 在真实 `AccountSettingsTab` 外层容器加载测试账号，进入账号序列、展开固定槽位再收起。
- 修复前回归失败：720×540 逻辑窗口中，收起标题实际高 **153px**，显著超过内容需要的高度。
- `CustomTab.view` 的 `SetMinimumSize` 属于原来的内部滚动页；被取出嵌入后仍继承原有尺寸约束。
- `SequenceManagementTab` 的根内容以 `stretch=1` 添加，分区纵向允许增长，嵌入后把剩余高度分配到说明、标题和状态。
- 原有测试验证了窗口宽度、只读状态及执行排序，没有验证展开到收起时的高度变化，因此未发现此次问题。

## 修复

| 文件 | 改动 |
| --- | --- |
| `src/gui/SectionPanel.py` | 分区纵向按内容排列；取出 CustomTab 内容后重置为默认布局尺寸约束、清除原滚动页的最小尺寸，并按内容限制纵向增长 |
| `src/gui/SequenceManagementTab.py` | 根容器按内容高度排列，不再以 stretch=1 填满父区域 |
| `tests/TestAccountUIPolish.py` | 新增真实外层容器的收起高度、内容高度释放、切换路由及再次展开回归 |
| `config.py`／`更新日志.md` | 同步版本 1.97.14 |

没有改写序列仓库、任务状态协议、账号特征码、材料账本或任务执行规则。
