# 海墟出口与下一层修复（1.82.01）

## 批准范围与证据

用户批准针对本机1.82.00日志中两处错误进行修复。没有审阅NAS ZIP，没有运行游戏任务。

- 20:50:47第9层上半完成，20:51:48出口60秒超时。暂停截图中角色位于围栏前，图标位于归一画面约(0.497,0.128)。原检测区域从y=150开始，返回None；仅扩大上边界到90，原模板匹配0.971。围栏截图提示可能受阻，但不证明整个60秒均卡住。

## 修改与边界

1. `sea_ruins_vision.exit_marker`保留原模板及阈值，ROI上边界从150改90，坐标还原同步修改，仍排除任务栏和HUD。
2. `AutoSeaRuinsTask._walk_sea_exit`在海墟局部封装原后台walker，每段最长1秒，段落间释放按键、重新对中，不再长期沿用centered状态。共用`BaseWWTask`不变。
3. 图标位置变化不足画面1%、两侧场景平均像素差不超过3且持续4秒，触发有限脱困：后退0.25秒、侧移3×0.25秒，至多3轮，左右交替。每一步重查阶段、图标、F提示、剩余预算；图标恢复不重置脱困次数。只是一种保守启发式，没有地图或完整路径规划，不保证绕过所有围栏。
4. 下一层导航使用现有稳定页面状态机，3次点击、至少5秒重试间隔，总上限120秒。必须再次确认结算页和预期下一层文案才可点击；加载或未知界面等待，不盲点。到达预期层详情页立即结束。
5. 保留异常暂停、释放输入和人工继续，不改变预设与buff策略，不改周本、深塔、多账号每日、公共导航或公共战斗代码。
