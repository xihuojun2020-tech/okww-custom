# 1.60.14 界面间距调整

## 问题与实现

公共 Tab 在调用设计参数后又强制使用 24 像素间距；嵌套页面仅清空边距而保留大间距。设置页未应用紧凑处理，账号外层处理又覆盖了内部更紧凑的设置。

- 将框架 design_system 纳入 custom_ok 随版本分发，页边距 16、页间距 8、设置行左右 8 / 上下 4、最小行高 40；内容仍按文字自然增高。
- 移除 Tab 的间距覆盖；嵌套内容清空页边距并使用 4 像素间距。
- 统一 SectionPanel、DisclosureHeader、FlatSettingRow 的紧凑默认值；账号外层保留账号紧凑参数，设置页应用紧凑处理。
- 移除普通分组底线、QGroupBox 顶线及任务详情顶线。保留输入框、按钮、任务容器与焦点边界，保持操作辨识度。
- 截图脚本加载实际发货的 custom_ok，支持 OKWW_UI_PAGES 逗号分隔页面类名以进行独立验收。
