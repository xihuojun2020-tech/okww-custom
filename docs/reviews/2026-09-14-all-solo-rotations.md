# 1.70.00 全输出角色单人分支验证报告

## 范围与结论

覆盖注册表去重后的 43 个主输出/副输出条目（漂泊者按一个条目计），以及启用输出配置的千咲。真实队伍仅一个成员时进入单人分支；三人队只剩一人存活不因此改判单人队。治疗定位保持原路径。

既有可独立执行的角色轴通过默认 perform_solo 复用，避免复制整套连招。爱弥斯、今汐、椿、绯雪、洛瑟菈和漂泊者添加专项单人处理，清宵复用上一版已修复的单人实现。基础角色仍使用基础技能轴，不宣称新增了完整优化连招。逐角色策略见 [单人输出说明](../references/solo-combat.md)。

## 问题与修复依据

- 原有多人轴可能等待变奏、队友增益或切人条件，单人队无法满足。公共调度清理残留变奏状态，专项分支使用真实技能/能量状态，不假造增益。
- 满协奏的退出或技能门槛会使部分角色提前结束输出。丹瑾、达妮娅、琳奈、折枝、长离等针对单人解除相关限制；安可单人可按设置释放解放。
- 切人不能在单人队推进状态。公共切人入口直接返回，奥古斯塔/卡提希娅战后不自切，夏空不伪造延奏时间；忌炎、相里要的单人等待增加时限。
- 单人大招依旧尊重 use_liberation 设置和实际可用状态；基础轴依次尝试声骸、解放、技能，冷却期间继续普攻。
- 漂泊者衍射、湮灭、气动沿用各自已有形态逻辑，单人跳过赞妮插入。导电、热熔、冷凝枚举及未知形态仅基础回退，不表示已实现未开放形态的专用机制。
- 自定义角色只覆盖 do_perform 时，加载器保留其单人执行优先级；显式 perform_solo 优先，避免内置分支绕过用户代码。
