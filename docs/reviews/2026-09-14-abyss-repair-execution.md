# 1.70.05 深塔错误修复实施报告

## 范围与证据

处理本机2026-09-14 14:40中塔全局配队中止、14:52战败后返回失败及丹瑾等级反复识别。证据来自本机打包版日志、14:40:22卡片截图及用户14:53:43失败页、14:54:20总览图；未审阅诊断ZIP，不标记NAS包为已检查。

## 修复结果

1. 删除中塔四层必须全部预分配才能开始的硬阻断。当前层有合法队伍即可执行；无队伍时保留原因并安全返回，继续下一塔。已处理塔从后续规划移除。固定季节抗性、等级门槛及共享体力计算不变。错误区分识别缺失、无候选、属性限制、近似搜索未覆盖及共享资源分配。
2. 三类结算返回（失败、最后一层完成、换队）复用有界返回方法：每次获取新帧，确认结算和精确返回按钮后点击，最多3次、30秒总上限、0.4秒轮询；两次点击至少间隔3秒。加载或未知页只等待，三塔标题同帧确认后返回。失败后结果保留失败和实际通关层数，继续下一塔，不修改真实星数或完成检查。
3. 已选角色不会被同一选择调用反向取消；保留点击前身份重定位、选中核验、取消后集合变化检查。增加动作编号、角色身份、塔层、页码、滚动条、归一化坐标及前后结果日志。
4. 真实丹瑾Lv.1在1080p复现旧OCR返回None。常规读取失败后，仅隔离白色数字、放大并补边再次识别，不猜测I就是1。未确认卡片只复读其局部信息，不再递归识别整页已确认角色。

## 计划差异与限制

- 返回方法复用现有结算OCR区域，精确匹配返回深塔，未新增更窄按钮区域；总览采用同一新帧的三个标题确认，未额外加第二帧稳定计数。异常仅保存最终返回故障截图，不每次重试保存整图。
- 不重写候选生成或扩大搜索规模。近似搜索未分配仍不代表绝对无解。
- 真实低等级夹具验证Lv.1/40；其他等级由既有测试覆盖，未宣称具备本次所有等级实机样本。
- 丹瑾的等级识别问题已修复，但用户观察到的实际反复点击来源未复现。新增保护和动作证据便于下一次精确定位，不声称完全解决点击根因。
- 本场战斗前切人超时的根因及胜率不属于本次已修复结论。
- 未运行用户游戏。用户需验证战败后返回总览、当前塔不再进入并开始下一塔；若丹瑾再次被选，请保留本轮手动诊断包。
