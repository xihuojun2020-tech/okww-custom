# 1.97.13 账号界面与固定槽位实施验收

## 范围

实施经用户确认的 `docs/superpowers/plans/2026-10-05-account-ui-polish.md`。沿用 PySide6、Fluent 控件及浅色蓝色主题，未增加外部 UI 依赖。此次包括账号草稿、固定槽位、生产执行顺序、总览刷新和本机源更新包安装。

## 已实施

- 顶部账号选择保留，压缩新建／更多操作，UUID 移入识别页；未保存草稿操作条按需出现，切换分类与账号保留草稿。
- 左侧前置任务总览、账号序列、账号执行顺序；右侧切换总览或设置。
- 槽位保存在账号 extensions，稳定 profile_id、登录身份、材料轮次保持；序列一 A1～A10、序列二 B1～B10，数字排序、占用冲突校验、空位跳过。
- 升级只按既有短名填入归属，保留既有执行参与集合；自定义序列兼容保留。固定序列禁止重命名、删除与手工改序。
- 实际序列快照按槽位排序；固定序列启动时不以当前登录账号旋转顺序，复用原有退登、识别和登录核验。账号切换测试仍使用生产方法。
- 序列页展示十个槽位、参与选择与配置摘要；执行顺序页只读，运行时展示冻结快照、本轮完成、运行中和下个账号。
- 总览提供五状态计数筛选、隐藏空分组、收起已完成、紧凑任务行及详情记录；最近失败尝试与最近完成分别展示。
- 异步刷新复用任务行，保留焦点、详情和筛选；同账号读取失败保留明确标注过期的快照并禁用标记，切换账号立即清除旧数据，拒绝过时异步返回。
- 每日 04:00、每周周一 04:00 状态刷新继续手动启动；深塔仍独立启动，人工提醒仍手动标记。自动战斗偏好与恢复逻辑保持。
